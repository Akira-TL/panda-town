# 学习版交易界面与参考图的实现对照

2026-11-01工作说明。已重新读取制作包的《开发执行提示词》《量化知识与游戏映射》，
逐张查看01–10参考图，并对照当前交易卡、规则编辑、知识互动和资料组件源码。
本说明记录确定的实现差异及待实测画面确认的风险；新版运行截图由协调者提供后再更新。
本轮未修改运行源码、启动浏览器、构建或生成新效果图。

## 优先确认的差异

1. **图表的可读性。** 参考图用较大的K线、量柱和读数讲因果；短屏主图目前高52像素，
   四价为紧凑读数。主要按钮可点不等于图形已经容易读。待看360×640有持仓、有成本、
   有规则的画面，优先保留当前价、选中K线、量柱与明确的买卖标记，避免再缩小关键字。
2. **主图买卖点缺少就近短图例。** 当前真实成交点已绘制，但“▲实际买入／▼实际卖出”
   文字仅在完整资料图出现。参考图的标记与交易后果对应更直接，可复用现有SVG标记，
   无须新增装饰图。是否在主卡加入极短图例，待截图确认留白。
3. **规则与背包的空间竞争。** 主卡现有三条件胶囊和真实入场／退出状态，与背包共行。
   短屏背包区域约76像素，多持仓需要横向滚动；需确认当前商品、份数及规则仍一眼可辨。
   不把“目标上限”画成已执行仓位，也不将已选规则写成已遵守。
4. **金额名称未完全一致。** 结果页使用“小镇币”，价格图单位仍写“模拟币/份”。
   参考图“金币”只是示意；宜沿已确认的小镇币统一可见单位，不改变任何计算。
5. **按需弹窗的文字密度。** 规则编辑仍显示完整条件、状态和原因；交易资料同时有工具入口、
   规则说明与数据声明。真实手机截图需检查进入弹窗后能否先看到图或当前操作，详细解释
   再展开，不能把每个可选模块都堆成默认必读内容。

## 可复用的现有元素与边界

- 八种商品图已在 `public/art/products/{bread,timber,fruit,chips,gold,flowers,coffee,tea}.webp`。
- 现金、资产、资料图标已有 `public/art/icon-{cash,assets,information}.webp`；熊猫头像为
  `public/art/panda-portrait.webp`。这些可用于少文字识别，无须另生一套风格。
- 卡片的奶油底、浅金边、圆角和森林绿主按钮已有真实CSS；后续优先调整层级、间距和读数，
  不把参考图整张盖到场景上，也不增加任务列表、等级或第二货币。
- 参考图中的全熊猫店主已被用户后续授权的15名多样化居民取代，不属于需要回退的偏差。
- 参考图的小时刻度、漂亮示例价格、比例和金叉仅为示意；当前使用真实日线和已知前缀。
- 银行完整比例、咖啡双曲线、指标和延伸资料按需展开，是为保留三维场景的当前安排，
  不据此认定它们已经达到参考图的视觉效果。
