# 公共交互语义与焦点约定

新增或修改决策、资料、证据、手记及确认区时，沿用本约定；经济动作、主要行动和状态形状见[公共经济与回合接口](engine-contract.md)。

## 操作入口

主要操作使用原生`button`，结算出售使用带可访问名称的原生`input`。图标入口有准确的中文可访问名称，文字选项保留完整标签；不可选项使用禁用状态并展示实际原因。键盘通过`Tab`、`Shift+Tab`移动焦点，通过`Enter`激活按钮，焦点所在位置有可见样式。

查看资料、证据和手记不消耗主要选择；镜头与简化动画设置不提交经济动作。骰子移动期间只有最终落点开启主要事件，岔路暂停保留剩余步数。阅读和选择保持不限时。

## 对话窗口

| 窗口/操作 | 打开与内部操作 | 关闭后的焦点 |
| --- | --- | --- |
| 资料 | 打开先聚焦“关闭资料”；首尾可操作控件通过`Tab`与`Shift+Tab`循环 | `Escape`或关闭按钮返回“先看看资料”入口 |
| 展开来源 | 展开按钮消失后聚焦该来源文章，继续导航到下一个可用操作 | 保持在资料窗口 |
| 比较/答题 | 按钮禁用或答案区替换后，焦点留在比较区或该题文章，解释位于相邻区域 | 资料关闭后仍返回原入口 |
| 原事件证据 | 打开聚焦“关闭证据”；禁用翻页按钮不进入焦点顺序，窗口内首尾循环 | `Escape`或关闭返回打开该记录的具体按钮 |
| 资产手记 | 打开聚焦“关闭资产手记”，长文滚动后关闭区仍可操作 | 关闭返回“资产与旅程手记”入口 |

资料、证据和手记的窗口有`dialog`角色、对应标题和模态声明。关闭区保持44×44像素以上，标题纸张背景覆盖滚动内容；程序标记不能代替对长文实际滚动图的检查。

## 重开与清除确认

重开和清除共用`SessionActions`，确认区为`alertdialog`。它嵌在原手记或报告中，默认聚焦“取消，保留本局”；`Tab`在取消和确认之间循环。`Escape`撤销本次确认并返回触发按钮，外层手记保持打开。

取消保持完整本局；确认重开生成新标识、1000现金和空证据；确认清除回到开场。存储删除拒绝时准确说明旧记录可能残留。确认语义与数据行为的更完整边界见[本机生命周期测试](../../tests/browser/lifecycle.spec.ts)。

## 减少动画

初始设置读取系统的 `prefers-reduced-motion`，玩家也可用“简化动画”切换。启用后缩短自动移动、固定角色动作并直接呈现最终开张状态；骰数、逐步落点、剩余步数、收入和结果继续由同一回合逻辑提供。切换设置不改变完整本局，阅读和选择不计时。新增演出必须同时支持此设置，不用隐藏金额或跳过主要选择来缩短动画。

## 复测入口

`tests/browser/keyboard.spec.ts`在同一个八天用例中仅使用键盘完成开场、岔路、工作、资料展开/比较、报告证据、确认重开及确认清除，并核对焦点归还；静止状态切换简化动画前后完整会话相同，工作后再连续按两次`Enter`也不重复入账。运行生产服务后执行：

```sh
npm run test:browser -- keyboard.spec.ts
```

长窗口滚到底的关闭命中区另由`tests/browser/dialog-scroll.spec.ts`验证。真实设备触控、全局镜头手势及所有辅助技术组合分别按对应任务记录，单一键盘用例不替代这些环境的验收。
