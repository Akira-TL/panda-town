# 图形主导的游玩界面

2026-10-31更新。用户明确要求尽量少字，用图和必要文本设计游戏。
本轮替换原长文工作台的默认呈现，计算、行为证据及完整画像继续保留。

## 主屏

每个决策只显示短标题、一句角色提示、实际价格图、最多两个数值和三个短行动。
默认价格图只保留商品切换与播放控制；均线、日期、来源、完整成交及计算说明按需查看。
按钮用具体行动，例如“顺着涨势买”“跌低了再买”“买好先放着”。

三项主要行动无需滚动同时可见。面板最多占半屏，镜头在决策时把熊猫移至上半屏，
保持小镇、角色、价格图与选项同时可见。信息不依赖颜色单独传达。

选择后的反馈优先来自价格回放、买卖点及实际数值；正文只保留一句结果。
默认界面不显示长篇规则、资料列表、全部参数、交易表或多张指标卡。

## 按需查看

“资料”打开完整规则、数据来源、计算条件、已保存运行、成交与可跳过理解题。
查看不消耗回合；主动查看才进入相应行为记录。详细结果不因主屏精简而丢失。
未运行检验前保持预留行情不可见，减少动画直接显示已开放区间。

结束直接进入量化研究画像。画像属于结果面板，可展开依据，不再追加推荐或任务。
