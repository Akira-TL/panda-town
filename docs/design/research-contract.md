# 量化章节与画像模块接口

本说明对应 `src/research/` 的第3版研究状态。产品规则以
[量化研究实施合同](../specs/research-core.md)为准；本文记录装配接口及作者定向测试边界。

## 公开接口与职责

| 接口                              | 返回值与责任                                                          |
| --------------------------------- | --------------------------------------------------------------------- |
| `createResearch(sessionId)`       | 创建第1天移动阶段的 `ResearchState`，不产生观察或交易                 |
| `dispatchResearch(state, action)` | 返回下一状态；错误阶段、旧日动作及重复标识返回原对象                  |
| `getChapter(state)`               | 返回当前位置导语、当天主要选项及可查看主题；第4天替代规则排除当前规则 |
| `buildResearchProfile(state)`     | 只读派生 `ResearchProfile`，保留本局证据副本及未观察部分              |

共同类型仅由 `model.ts` 定义。章节不维护现金账本，画像不重新计算交易。
界面直接使用章节选项及画像类型，不复制选择后果或画像推导。

## 阶段和运行记录

到达落点使 `travel` 进入 `decision`；当天主要选择进入 `feedback`。
继续推进至下一天移动，第8天继续到 `exhibit` 并将展位设为咖啡馆，
打开画像后为 `report`。导航模块负责同步实际位置；地点不改变固定八章次序。

第3天保存规则版本1并立即运行研究段。第4天保留或改变规则都实际重算，
改变规则才升版本。第5天改目标投入上限，第7天改费用或检查频率，均升版本并重算。
同参数得到相同运行标识，状态只存一份相同运行，但接受的运行操作保留独立证据。
历史运行不覆盖，展示曲线必须读取相应运行自己的参数及数据版本。

研究段与检验段分别从1000模拟币起步，含起点的资金曲线分别为121点与61点，
不能拼成一条连续持仓路径。资金、成交及费用来自实际模拟器；题目、解释、
最终选择不会发放收入。投入上限为0时，当前现金策略资金维持1000且无成交费用，
此前较高投入版本的历史结果仍然保留。

## 暂缓与已揭晓数据

第6天暂缓不运行检验、不显示预留段。第7或第8天相关资料中的明确运行操作
可以首次补验，采用操作当时的规则、投入比例与费用。原暂缓证据保留。
同章同主题再次打开不增加独立观察，也不重复运行；跨日查看同一已揭晓结果不产生新检验段。

曾运行检验后再改变参数，旧结果保留，当前状态为 `needs-new-data`。
随后查看旧结果不能把当前版改回已检验，不能将同一批已揭晓数据重新称为未见数据。
画像因此可以同时描述“本局实际运行过检验”和“当前版本仍需另一批新数据”。

## 画像消费接口

`ResearchProfile.sections` 分为研究兴趣、证据习惯、策略与资金取舍、工具使用。
每条事实含实际计数、可观察机会、状态及证据标识；按独立章节情境去重。
`knowledge` 仅包含首次已答题目，未答不进分母；`unknown` 保留未知与旧参数限制。
`evidence` 可供界面展开动作时选项、已查看主题、参数、版本及所引用运行。

画像不按模拟收益给人打分，不从当前仓位补造过去操作，不把自动曲线当主动查看，
不评一般人格、编程能力或现实投资适当性。三种最终决定都完成同一展会目标，
不会为了填满面板自动追加检验或答题。

## 作者测试覆盖

`campaign.test.ts` 通过公共动作运行真实模拟器，覆盖动作幂等、费用修改使旧检验失效、
暂缓后的首次补验和跨日查看、全现金平线，以及三种最终决定均可进入展会和画像。
`profile.test.ts` 覆盖独立情境计数、外局过滤、空证据不补造、首次答案冻结，
以及旧参数检验事实与当前版未验证限制并列保留。

这些是确定性的模块作者测试，不证明三维画面、按钮焦点、移动布局或完整浏览器流程。
构建与真实界面检查由集成负责人另行执行。
