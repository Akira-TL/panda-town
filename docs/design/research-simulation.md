# 研究报价与模拟计算口径

来源为[量化研究实施合同](../specs/research-core.md)。本文件记录`src/research/data.ts`与`simulation.ts`的实际计算口径，供章节、工作台与画像共同引用。共享结构以`src/research/model.ts`为准。

## 数据与公开边界

数据版本为`panda-binance-spot-1d-20250101-20250719-v1`，固定采用2025-01-01起200期真实历史现货日线并映射为游戏商品，不来自PandaData。

| 用途     | 期数 | 日期              | 公开接口             |
| -------- | ---: | ----------------- | -------------------- |
| 首次预热 |   20 | 2025-01-01至01-20 | 模拟内部使用         |
| 研究     |  120 | 2025-01-21至05-20 | `getResearchData()`  |
| 留出检验 |   60 | 2025-05-21至07-19 | 仅实际运行检验后展示 |

价格现在直接取固定区间的真实历史日线，不再使用分段斜率、固定扰动或取模成交量。
原始字段、各月校验和及单位转换详见[真实行情来源](market-data-source.md)。
竹材和松果是游戏映射，未连接PandaData；历史及派生数据的第三方许可与源码MIT分开。

四处传输问题是关卡人为设置的教学错误，原始历史数据并未发生这些错误。
收到值与同日源恢复值由 `getDataIssues()` 保留，逐项字面核对见 `data.test.ts`。
不再保留旧生成器的112.30等恢复数值作为新行情的依据。

`getDataIssues()`保留日期、资产、原值、恢复值与说明。恢复只重读同日期确定性演示源，不读取未来样本，也不用前一日成交量证明本日可交易。此处恰有可核对的演示原始副本；不能把这种恢复能力宣传为能从缺失金融数据推知真实价格或流动性。

`getSimulationInput(segment)`是供模拟入口使用的内部接缝，返回该段报价及之前20期预热。检验段使用研究末20期（05-01至05-20），不会将检验自身报价放进预热。两个分段各自以1000模拟币起步，不继承上一段持仓或财富。

界面只公开研究段。只有本局`state.runs`已有实际`validation`运行，且所展示运行属于该本局时，才读取检验报价画价格/均线；未运行时不提前装入隐藏表格。该边界约束游戏研究过程，本机包中的演示序列不是服务端保密数据。

## 三种规则

简单移动平均线（Simple Moving Average, SMA）是固定窗口内收盘价的算术平均值。参数固定，不在留出段搜索最优参数；界面使用`getRuleDescription(rule)`取得同一份规则说明。

| 规则        | 参与与退出                                                                                 |
| ----------- | ------------------------------------------------------------------------------------------ |
| `trend`     | 上一期及之前的5期SMA高于20期SMA时参与，反之退出                                            |
| `reversion` | 上一期收盘低于20期SMA的98%时进入；已有真实持仓且尚低于均价时继续持有，回到均价或更高时退出 |
| `hold`      | 首期开盘等权配置两资产，随后不调仓；改变频率不改变此持有规则                               |

趋势和均值回归每1或5期检查一次，检查索引从该运行段第0期开始。无足够20期前史时持币，不能借用未来值补窗口。每个资产独立触发，选定目标比例在触发资产之间等分；未触发则保留现金。数值比较采用`1e-10`相对容差，避免相同小数价格仅因浮点尾差制造信号。

上一期收盘形成参与方向；下一期开盘按当时价格、现金与目标权重确定委托数量并成交。结果的`signalDate`与`date`分别记录两个时点。当前期收盘仅用于该期末计值和下一次信号，不参与本期开盘决策。

## 撮合、成本与委托

初始资金通常1000；目标比例仅为0、30%、60%或研究比较用的100%。本模块也接受正的其他初始资金，便于独立手算。数量允许小数份额，没有借款、负现金、做空或杠杆。

目标比例以扣除本次预计交易成本后的开盘净值为分母。模块在0至交易前净值之间用固定60次二分求一致的成本后目标值，再先卖后买。买入价格为开盘×（1＋滑点），卖出为开盘×（1－滑点）；买卖费率都按实际成交金额扣除，1基点等于万分之一。比例是检查时点的目标，价格变化或成交受限后实际比例可以偏离。

每根的成交量是各资产可成交数量上限。买入还受含费用的可用现金限制，卖出受实际持仓限制；零成交量产生拒单，部分流动性产生部分成交。`orders`保留请求数量、实际成交、`filled`/`partial`/`rejected`及理由；`trades`只记录真实非零成交、价格、费用与成交后现金。未成交部分只在当期有效，不自动排队；下一检查期可依据当时规则形成新委托。

现金与数量使用浮点计算，不逐笔强制四舍五入到分。`1e-10`份额以下的数值残差不生成交易，拒单实际成交数为0。费用/滑点必须为非负有限值且小于10000基点；报价价格需正且有限，成交量非负且有限，日期有效、严格递增、不重复。输入不合格时拒绝运行。

## 对照与指标

对照始终是同期间、同初始资金、相同费用/滑点与成交量约束的100%初始等权持有，独立模拟账户不挤占策略账户成交量。策略选择零仓位时对照仍参与，不能把对照也缩成零来抹去差异。对照受限未完全成交时，在说明中明确记录。

每条曲线先记录未成交的初始1000点：日期为预热末日，没有预热时为首报价前一日；它不代表额外一根行情。随后每期按收盘记录现金、持仓市值合计及对照，所以120/60期分别得到121/61点。期末不强制卖出，剩余持仓按最后收盘计值，不能虚构一笔不存在的退出费。

净收益金额为末期净值减初始资金；净收益率与对照收益率均为该差额除初始资金。最大回撤包含初始点，按到过的最高净值至其后低点的最大跌幅计算。返回比率用0.12表示12%，没有年化、综合能力评分或收益保证。

运行标识包含数据版本、完整配置及有序报价指纹，输入相同则逐字段相同，不用时间或随机数。指纹用于本局追踪，不作加密校验。传入报价、配置和预热均不被修改。
