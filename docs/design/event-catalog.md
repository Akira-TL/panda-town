# 事件与场景目录

状态：配套设计草案，规则以 [首版规格](../specs/panda-town.md) 为准。编号仅作为稳定内容标识。数值尚未试玩，调整必须同步规格及相关验收，不能由各街区分别决定。

## 1. 地点与路线

主路顺序：广场 → 面包店 → 杂货铺 → 公告牌 → 集市 → 研究站 → 小桥 → 银行 → 礼品店 → 对手小店 → 河岸观景点 → 咖啡馆 → 广场。

支路甲：杂货铺 → 修理摊 → 花园 → 集市。支路乙：小桥 → 音乐角 → 码头 → 礼品店。主路和支路都按边一步；岔路预览明确两条路径及剩余骰子步数，骰子不足时正常停在途中地点。路过的店不自动买卖。

主路共 12 点、支路共 4 点。分支选择对应可预览的经营、生活或社交机会，不通过暗改骰子保证落点。第 1、4、8 天的叙事信息全图可达。

## 2. 十二个基础事件

以下列出两项主题选择，第三项统一为“临时工作 +250”，详见规格。查看资料与选项详情通常不消耗主要决策；知识题属于可跳过的资料互动，不另外奖励金钱。已完成的一次性选择改为后续对话，不能重新发物品或收益；仍可观察/暂不行动或工作。

| E01 面包店新口味 | 面包店；首次消费可用 | 60 买常规面包 / 120 买新口味礼盒；即时扣款，角色回应与回顾留痕 | 仅在两项均可负担时比较价格与新奇取舍；物件不增加能力值 |

## 3. 知识资料与固定答案

K01：演示营业额第一天 100、第二天 120、第三天 90。问“第二天比第一天增加了多少？”选项 20 / 30 / 无法知道；正确为 20。解释使用可见数据做减法，只支持这道读数题的表现。

K02：消息甲为“商家希望下周涨价”，消息乙为“截至今天实际成交价仍为 100”。问“哪条直接描述已经发生的成交？”选项甲 / 乙 / 两条都不是；正确为乙。解释区分意愿与已发生事实，不由一题推断综合金融知识。

两题都可跳过，不影响资金、不锁住主线。首次提交后显示答案；后续查看不新增答题次数，不能把答案已经显示后的作答当独立测量。面板显示已答题数分母，无题即未评估。

## 4. 角色与叙事节奏

- 玩家熊猫：背包、围巾等固定识别物，行走/待机/回应动作一致。
- 咖啡馆店主：第 1 天讲目标，第 8 天根据现金呈现开张或筹备中。
- 面包店与杂货店居民：共享基础熊猫形体，以服饰道具区分；记住本局一次消费或帮忙后的回应。
- 研究站工作人员：引导看演示资料，明确来源和截至时间，不承诺投资收益。
- 电脑对手：独立筹备小店，第 2 天可提出一次采购优惠，第 4 天回应行情，第 6 天显示经营进展，第 8 天共同庆祝或鼓励。其他回合播放一句实际账本行动摘要。

对手起始现金同为 1000，每回合基础收入 150；第 2 回合若资金足够买摊位，其他回合优先工作 250；不买工具或投资。以自己的现金与摊位收入结算，达标仅改变其店面表现，不结束玩家回合。优惠只服务 E08，不抢走玩家固定工作机会。

第 1 天开场约 20–30 秒；每回合含移动与对话约 25–40 秒；结尾约 40–60 秒。说明、选项和资料都可由玩家按自己的速度阅读。长篇背景留在可展开区域，主对话一至两句，选项显式给成本和直接后果。

## 5. 一般人格线索的保守呈现

以下是待验收的情境展示规则，不是新的量表：E01 与 E07 均在可负担时主动选择新奇物件，可展示“两次选择了新奇物品”作为探索线索；E04/E11 的资料核对与 E12 的主动盘点可分别说明核对和筹备行为，但不能直接称尽责性高。E10 主动交谈与 E12 主动谈计划可展示“在两处主动发起交谈”，不等于现实外倾性评分。

E08 合购有经济动机，E09 求助有成本差异，均只列原始合作行为，不单独支持宜人性判断。首版没有情绪稳定性的有效观察规则。所有人格区域允许全部显示线索不足；完整报告是完整呈现已知和未知，不是强制填满五维。
