# Panda Town 量化主线与文案重规划

日期：2026-10-31。用户在查看实际游戏后指出剧情和结尾画像与PandaAI量化场景脱节，并已明确确认：**唯一目标改为“八天完成一份自己的量化策略，在小镇策略展展示”。** 本文给出配套的内容方案；具体章节、数值和画像规则供本轮审阅，尚未实现。当前试玩仍是旧版开咖啡馆内容。

## 1. 本轮改变什么

原主线中的消费、打工、买工具和攒3000金币，不再承担主要决策。原“开张/筹备中”及消费称号，不能继续作为新方向完成的证明。现有童话小镇、真实模型、16个地点、掷骰自动移动、两处分支、双镜头和本机记录可以复用。

新主线为：**提出研究问题 → 检查数据 → 定义规则 → 历史回测 → 选择投入与风险 → 新数据检验 → 核对费用与成交 → 展示策略与本局画像。**

游戏仍面向零金融基础参观者，一局八回合，目标5–8分钟。结尾仍直接展示画像面板，保留证据、重开与清除；不恢复已取消的课程推荐、额外研究任务或外部跳转。

## 2. PandaAI 的实际位置

官方Qube将自然语言研究意图、策略/因子生成、回测、版本迭代与仿真放在同一研究流程；PandaData提供底层金融数据；QuantSkills提供可复用分析能力。这是本方案的产品依据，不表示游戏已调用这些服务。[Qube使用指南](https://www.pandaaiquant.com/docs/qube)、[PandaData数据服务](https://www.pandaaiquant.com/docs/data)、[QuantSkills官方社区](https://www.quantskills.ai/)

玩家在每个章节实际打开“PandaAI研究工作台”，得到可核对的表格、规则、曲线、风险、交易或版本记录；不能仅在屋顶挂PandaAI招牌。工作台中的每次运行都展示输入、方法和输出。

| 操作         | 必须产生的实际结果                                   |
| ------------ | ---------------------------------------------------- |
| 核查数据     | 显示来源、区间、缺失或异常记录及处理说明             |
| 选择规则     | 保存可读规则和参数，不只改一个角色称号               |
| 运行回测     | 依据同一数据计算现金、持仓、交易和净值，提供统一对照 |
| 改变投入比例 | 重新计算相应资金曲线与途中下跌，保留原版             |
| 检查新数据   | 展示事先保留的数据结果，不能挑表现好的区间替换失败   |
| 加入费用     | 实际扣除费用，并能从交易记录复核                     |
| 展示策略     | 汇总数据、规则、风险设置、验证范围与最后决定         |

用户尚无PandaData权限，因此近期实现采用明确标注的本地演示数据和计算。工作台标注“PandaAI研究流程演示｜本地计算｜尚未连接PandaData”；服务接入状态在旁单独显示。后续获得正式权限再替换执行适配层，不能把预制解释文案称作已经运行PandaAI。

## 3. 故事、目标与开场文案

小镇即将举办策略展。玩家是新来的研究搭档，获得1000模拟币，与另一位熊猫研究者一起，在八天里把一个朴素想法变成能展示依据的策略。商店和居民提供研究的情境：热销消息、报价记录、数据包、交易成本与对手的漂亮曲线。

唯一完成目标是提交一份包含研究依据的策略展品。收益高低是实验结果，亏损、保留现金或决定暂缓模拟运行，都能完成故事。没有多条胜利指标，不按答题数或赚到的钱决定是否准许展示。

**开场主文案**

> 小镇策略展，八天后开幕。
>
> 带上1000模拟币，和PandaAI把一个想法变成一份自己的量化策略。沿路找数据、试规则、看风险，最后告诉大家：你选择了什么，依据是什么。

主按钮：“开始我的策略之旅”。辅文：“不需要写代码。收益不代表能力，所有资金均为模拟。”

**最初一次概念解释**

> 量化策略，就是把想法写成可以重复执行的规则，再用数据检查它。

PandaAI搭档：“规则怎么写、结果怎么看，我会陪你一起做。每次只需要决定眼前这一步。”

## 4. 掷骰与主线的关系

八个研究章节按回合顺序出现，不能再依赖随机落点是否恰好到了研究站。每个地点都能打开随身工作台，用当地角色和故事引入当天同一个核心任务。

骰子继续决定移动距离；岔路预览不同的居民、主题和额外资料。路过不触发主要事件，落点只有一次主要选择。查看曲线、比较资料、听解释不另外消耗回合。相同研究机会在两条路线都能获得，不因骰子运气少掉风险或验证环节。

地点为剧情提供差异，章节维护数据和策略的连续性。不能为16个地点各写一套账本，也不能把每日主线变成随机知识题抽签。

## 5. 八天主线与可直接使用的文案

每章默认一段短对话、一张主图/表和三个清晰选项。按钮先用普通话描述；专业名词在首次出现时解释。以下收益、回撤、费用等字段均由真实计算填入，不预写漂亮数字。

### 第一天：你想解决什么问题

场景冲突：对手举起一张收益很高的海报，向导问玩家是否也只想追求最后那个数字。

PandaAI搭档：

> 同样一笔模拟资金，有人更在意最后增加多少，有人更在意中途会跌多少，也有人希望少操作。你的第一份策略，想先研究哪个问题？

选项：“我想研究怎样争取更多收益”／“我更想控制中途的损失”／“我想尽量少操作、少付费用”。

结果：记录玩家主动表达的研究意图，决定工作台默认先展示哪项指标；所有指标仍可打开。它是本局自述，不直接变成风险等级或人格判断。

反馈：“研究问题已记下：{研究意图}。接下来用同一份数据试一试。”

### 第二天：数据先过一遍眼

场景冲突：居民送来一份价格记录，里面有缺失样本和待核对记录。玩家可以选择优先检查什么。

PandaAI搭档：

> 价格曲线看起来很完整，但有一条记录还没核对。先弄清数据怎么来的，后面的结果才说得清。

选项：“先核对来源和日期”／“先定位缺失与异常记录”／“请PandaAI检查，并解释处理结果”。

结果：显示相应检查过程，并保留完整数据质量说明；正式研究统一采用已核验的数据副本，避免不同检查顺序暗中改变比较条件。自动检查不扣能力分，查看原始记录也不自动证明技术水平。

反馈：“本次使用{区间}的演示记录；发现{问题}，处理方式为{方法}。原记录仍可查看。”

### 第三天：把直觉变成规则

场景冲突：集市上有人说“涨得好就继续买”，另一位说“跌下来才便宜”。两种想法都需要说清条件。

PandaAI搭档：

> ‘看着不错就买’还不能重复执行。我们先给想法加上明确条件，再把它放回过去试。

选项：“最近走势走强时参与”／“偏离近期平均价格后尝试回归”／“按固定比例持有，先做简单对照”。

展开解释分别介绍趋势跟随、均值回归和固定配置；不把三者写成收益保证。确认前用一句普通话展示所用数据、触发条件、持仓和退出规则，允许查看计算细节。

结果：生成策略版本1和明确参数；选择可改变实际模拟交易。固定配置也是合法研究对象，不被当作偷懒。

反馈：“你的规则已保存：{普通话规则}。只有当时已知的数据会参与判断。”

### 第四天：历史里会发生什么

场景冲突：对手声称自己的结果更好，但图上没有对照，也没展开交易记录。

PandaAI搭档：

> 回测，就是把规则放进已经发生的数据里，看看当时会怎样。我们已生成同一期间的结果，你想先从哪里判断？

选项：“先比较策略和固定持有”／“先看中途最大的下跌”／“先检查每次买卖与规则是否一致”。

结果：三类结果始终可获得，主要选择记录玩家主动的检查重点。界面必须显示同一初始资金、同一区间和同一费用口径；后续可以继续展开其他结果。

反馈：“该区间净收益{netReturn}；同期对照{benchmarkReturn}；最大回撤{maxDrawdown}。这些是历史结果，后面的数据还没有揭晓。”

最大回撤首次用普通话解释：“这段记录中，从已经到过的高点，到后来低点的最大跌幅。”

### 第五天：愿意投入多少

场景冲突：即使最终收益接近，两条曲线的中途波动也不同。银行工作人员邀请玩家明确投入规模。

PandaAI搭档：

> 这一步选择实际参与的比例。保留现金会减少涨跌的影响；投入更多，收益和损失都会受到更大影响。你想怎样继续这个模拟实验？

选项：“投入30%，其余保留现金”／“投入60%，其余保留现金”／“暂时保留全部现金，继续看结果”。

结果：按所选比例重新计算，并列保留原结果；不借款、不加杠杆。先展示可见历史跌幅和比例对应的模拟金额，不能隐藏代价来诱导选择。

反馈：“已选择投入{allocation}。这记录的是你在当前信息下的资金取舍，不由本次盈亏决定对错。”

### 第六天：换段数据，还站得住吗

场景冲突：新的行情记录抵达，有的策略失效，有的仍可继续。此前漂亮的曲线不能自动解释这段数据。

PandaAI搭档：

> 这批数据没有参与前面选规则。先把原规则放进去，才知道它离开熟悉的那段历史后表现怎样。

选项：“保留原规则，检验这段新数据”／“先看检查说明，再决定是否检验”／“先不采用，标明还缺哪些证据”。

结果：选择检验时首次揭晓预留数据的结果；不采用也保留相应说明，不补造已完成检验的记录。若之后依据已揭晓结果修改参数，新版本标为“还需另一批新数据验证”，不能重复把同一批数据叫作未见数据。

反馈：“研究段与新数据段分别为{旧结果}/{新结果}。当前版本{版本号}，检验状态：{状态}。”

### 第七天：账面结果真的拿得到吗

场景冲突：码头送来交易回报。对手的高收益里有频繁交易，加入费用和更现实的成交条件后，结果发生变化。

PandaAI搭档：

> 发出买卖指令不等于已经成交。每次交易还会付费用；先把这些算清楚，再决定要不要修改规则。

选项：“保留规则，计入费用后再看”／“减少交易频率，保存为新版本再比较”／“提高费用假设，检查结果有多敏感”。

结果：真实计算净收益、交易次数、总费用和成交差异；减少频率只在研究段重试，不反复挑选检验段最好的参数。交易量、价格、现金和执行时点使用统一约束。

反馈：“交易{tradeCount}次；总费用{fees}；计费前后结果为{grossReturn}/{netReturn}。修改版本保留原版对照。”

### 第八天：带着依据登场

场景冲突：策略展开始。玩家不需要证明自己一定赚钱，需要清楚说明规则、证据和下一步态度。

PandaAI搭档：

> 你的策略卡准备好了：用过的数据、写下的规则、看到的风险和还没解决的问题都在这里。你想怎样介绍它？

选项：“这版先做小规模模拟运行”／“保留展品，说明还要修改的地方”／“展示研究过程，说明我暂不采用”。

三项都完成唯一主目标。第一项只是本局决定，不自动替玩家启动真实或外部仿真交易。若规则或验证尚有缺项，策略卡明确标注，不伪造通过认证；后两项没有失败惩罚。

结尾主标题：“你的第一份策略，带着依据登场了。”

说明：“下面看看这八天的选择，让我们实际了解了什么。”

主按钮：“查看我的量化研究画像”。

不再让建筑分别产出无关的消费、送礼或打工决策。地点独有的导语、道具与附加资料用于包装当前章节，主任务仍由回合决定。

| 音乐角 | 持有周期与交易频率的生活化解释 | “节奏快慢会改变交易次数，但快不等于好。”             |

这些名称是游戏内的普通描述，不是PandaAI新的官方产品名称。真实资产仍采用金融数据或明确虚构的金融价格序列，不把面包销量直接叫作证券行情。

## 7. 画像面板重排与示例文案

主标题：“你的量化研究画像”。副标题：“来自本局实际选择，点击查看依据。”

顶部先展示策略摘要：研究意图、规则版本、投入比例、研究/检验区间、扣费后结果、最大回撤、最后决定。策略表现与人的观察分区呈现，收益不进入能力分。

| 主区块           | 可展示内容                                           | 可直接使用的句式                                                             |
| ---------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------- |
| 量化研究兴趣     | 主动选择和查看的收益、风险、数据质量、规则或成本主题 | “你在两个不同情境主动关注交易成本：查看净收益差异，并提高费用假设再次检查。” |
| 数据与证据习惯   | 来源核对、异常检查、统一对照、新数据检验和版本保留   | “你先核对了数据日期，在对比时又查看了相同区间；两次记录都可展开。”           |
| 策略与资金取舍   | 实际规则、投入比例、已展示条件下的保留/减少/暂缓     | “在看到{已知风险}后，你选择投入30%；这描述本次取舍，不是固定风险等级。”      |
| 研究工具使用方式 | 实际使用自动解释、原始记录、规则细节与对照的情况     | “本局两次主动查看了规则或交易细节；尚不能据此判断编程水平。”                 |
| 已作答知识       | 原题、首次答案、正确数/已答数、解释                  | “已答2题，其中1题正确；未答题不计入分母。”                                   |
| 未知与变化       | 未展示机会、未运行步骤、相反选择及信息变化           | “你先关注收益，看到新数据后暂缓采用。面板保留这次变化及当时已知信息。”       |

称号可以作为装饰，例如“先看依据的研究搭档”，但先有明确触发记录，不生成正式研究者分类。原来的“踏实筹备的店长”“新奇消费偏好”等不再占据主摘要。

一般人格不再承担PandaAI量化画像主结论。用户先前希望保留的一般人格线索可以放在次要折叠区，仍沿用有来源的框架及“不足/未评估”；没有新的合适情境就留空，不能把趋势策略、持仓比例或一次合作直接映射为人格。

### 同样收益，不同画像

玩家甲先选更高收益，但主动核对数据、展开对照、检查费用，最后投入30%。报告陈述其收益意图、研究操作及具体投入，不直接写“激进”。

玩家乙同样选择更高收益，更多使用自动解释，最后投入60%并愿意继续模拟。报告陈述其工具使用及在当前条件下的资金取舍，不写“能力较低”。

即使二人碰巧得到同样收益，主画像也应因实际过程不同而不同；反过来，相同过程碰到不同结果，不应自动改变人的画像。

## 8. 证据记录规则

研究意图、工具调用、资料打开、明确比较、规则确认、回测运行、参数修改、资金选择和最终决定分别记录。每项保存本局标识、回合、独立情境、实际展示选项及可用性、所见数据、数据区间、策略版本、参数、实际结果和来源引用。

能力、兴趣、偏好和自述分别展示。主动查看不等于理解，自动解释不等于不会操作；只有客观题支持“本题理解情况”。随机落点、观看时长、动画设置、误触关闭均不作量化兴趣证据。

同一章节重复点击、同一结果反复展开不增加独立情境。至少两处不同情境一致时才能用“本局多次关注……”；该门槛是产品展示规则，不是经验证的心理测量阈值。只有一次时写“本局一次选择……”，不填默认百分比。

为PandaAI展示的结构化摘要至少含：观察主题、实际行为、机会数、支持记录、不确定部分、用户自述和最后研究决定。默认本机保留，不因面向PandaAI就自动上传。

## 9. 两道可跳过的量化理解题

旧“营业额120－100”替换为与研究过程相关的内容，题目藏在相关解释中，不把八天做成连续考试，也不给答题金币。

1. 回测后：“过去这一段盈利，是否保证下一段也盈利？”正确依据为“不保证，需进一步检验”。
2. 费用后：“规则和成交不变，计入额外费用后，净收益会比未计费用时更高吗？”正确依据为“不会，费用会减少这组交易的净结果”。

每题支持跳过、首次答案冻结、解释和报告回看。未遇题或全跳过显示未评估；只按已答题显示原始情况，不换算量化能力总分。

## 10. 数据与模拟计算的最小边界

游戏的一天是一个研究章节，不是一根行情数据。八天研究的数据应包含足够的历史样本，例如事先固定的120个研究期样本与60个后续检验期样本；这只是教学规模，不构成统计充分性或策略有效性承诺。

近期使用两项明确虚构的模拟资产，字段含日期、价格、成交量及有效性；具体序列、频率和区间写入版本化清单。规则限制为两类简单价格规则与一个固定配置对照，统一撮合、费用、现金和持仓口径，不引入融资或真实交易。

因果顺序必须成立：只用当时已知数据形成信号，按随后允许的成交时点执行；费用计入成交，委托状态与实际成交分开。新数据在选规则和初次调参时保持不可见，检验失败也保留。官方策略指南同样强调数据、信号、风控、委托、回报、复盘及避免未来信息。[PandaAI策略开发总览](https://www.pandaaiquant.com/docs/strategy)

数值、图表和反馈由同一次运行生成。相同数据与参数可重复得到相同结果；修改仓位或费用应产生可手算的差别。演示中模拟资产的盈利不能被文案说成PandaAI推荐结果。

## 11. 展会节奏

建议开场20秒，八章各30–40秒，结尾与画像50–70秒，合计约5分10秒至6分50秒；详细资料和两题按需展开。该数值是阅读与操作预算，仍需真实试玩计时，不设置倒计时。

默认文案每次只推进一个问题，长解释放展开区。图表显示金额及普通话说明，不要求玩家先认识夏普比率、因子相关系数等术语。高级指标可放详情，不占核心按钮。
