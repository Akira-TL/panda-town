# 户外居民的派生与接入

公告管理员、修理师傅、园丁、乐手、码头看护人、河岸读者和小镇向导，均派生自已有 Tripo 熊猫模型及本地十骨骼处理结果。没有新生成七个不同的 Tripo 人物，也没有绕过此前独立人物图生成被拒绝的限制。帽子、围裙及信件、扳手、盆花、笛、网兜、书、地图为项目自建几何。

七位户外居民与已有七位店内居民分组登记，分别保留 `OutdoorResidents` 与 `TownResidents` 根对象。户外角色名为 `OutdoorResident:<location>`，身份工具名为 `RoleTool:<tool>`。三维场景确实加入对象后才设置 `data-outdoor-resident-count` 及 `data-outdoor-resident-locations`，既有 `data-resident-count=7` 继续只表示店内组。

网格、纹理继续共享移动版熊猫资源，各角色通过 `SkeletonUtils.clone` 获得独立骨骼并播放已有 `Idle` 动作。角色在玩家18米范围内才推进动作；简化动画开启时暂停动作。到访相应位置时，居民实际转向玩家。没有为这七位居民增加模型请求。

人物沿实际地形接地。码头和河岸单独选择岸上位置，基于河曲2000个采样点检查，至河中心最短距离分别为5.21米和4.66米，大于2.2米半河宽。该检查仅说明没有放在河中；服饰、人物和户外设施是否遮挡，仍须新构建的七处运行近景确认。

本阶段类型检查和坐标有限值检查已通过，实际渲染、移动设备性能以及镜头遮挡将在整合构建中检查。此派生关系继续遵从原资产来源与许可记录，不新增独立模型授权主张。
