# 熊猫骨骼与动作

2026-10-31 以已加工桌面与手机版静态模型为源，运行 `scripts/assets/rig_panda.py`。输入和输出为不同文件，未覆盖原始 GLB 或静态两档。

实际输出为 `public/models/panda-rigged.glb`（16,917,596 字节）和 `panda-mobile-rigged.glb`（4,769,712 字节）。保存两档骨骼 Blender 源与 `panda-rig-report.json`。规则权重覆盖所有顶点，保留 UV 和纹理；骨骼包括躯干、头、双上臂、双前臂、双大腿与双小腿，共十根。

重新导入实际桌面导出文件，检查得到十根骨骼、一个带骨骼蒙皮的网格，以及 `Idle`、`Walk` 两段真实动画。运行场景由 `AnimationMixer` 在移动时切换行走，停下后切回待机；减少动画设置停止播放，不以整个模型跳动代替四肢动作。

脚本首轮校验发现：网格坐标应用世界矩阵后，包围盒尚未刷新，旧高度约 0.979 米。实际导入尺寸约 1.833×1.416×2.101 米；添加网格及场景更新后重新核验通过，未移除尺寸门禁。探针见 `scripts/assets/inspect_rig_space.py`。

预览 `panda-rigged-walk-front.png`、`panda-rigged-walk-back.png` 是行走第七帧的独立渲染，目视四肢有动作，眼耳与背包轮廓保留。连续步态、脚底接地及肩部形变还需要真实游戏镜头检查；单帧预览不等于完整动作验收。来源许可沿用本目录 README 的待核账号计划，不自动标为 MIT。
