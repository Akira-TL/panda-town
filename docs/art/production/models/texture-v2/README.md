# 模型运行纹理压缩

使用 `scripts/assets/compress_model_images.py` 调用 Blender 的图片保存、重新载入、打包和 GLB 导出功能，未手动改写容器索引。仅不透明颜色及粗糙度／金属度图片改为质量 94 的 JPEG，法线仍保留 PNG。原始 GLB 和高模保留。

`compression-report.json` 覆盖已存在的熊猫与面包店；`new-models-report.json` 覆盖用户新交付的八个模型。每个导出文件都重新导入 Blender，比较骨骼数、动作名称和 UV 层；熊猫两档仍为十根骨骼及 `Idle`、`Walk`，其它静态资产不伪造动画。

`preview_compression.py` 用相同相机、灯光、姿势和渲染参数生成 `compare-*-before-*.png` 与 `compare-*-after-*.png`。已目视熊猫和面包店的前视对照，材质颜色、轮廓及动作未见明显变化；后视对照一并保留。此处是单体压缩质量检查，不能冒充游戏运行截图。

实际运行十个桌面模型合计 30,855,612 字节，十个手机模型合计 10,353,132 字节。背景邻屋和树共享资源，不重复下载每个实例。加上本轮九张 WebP 运行图约 1.22 MB 后，模型和图片预算仍需按浏览器真实请求核验；未据文件总量声称首屏 15 MB 目标或实体设备性能已达标。

本目录 JPEG 为本机加工中间件，GLB 内已嵌入它们，游戏无须单独读取。来源及许可沿用原资产记录，未改标 MIT。
