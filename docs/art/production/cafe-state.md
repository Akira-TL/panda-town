# 咖啡馆入口的筹备与开张状态

参考为已生成的 `cafe-opening.png`：木质入口、可见营业状态、暖色门灯和迎宾角色。真实咖啡馆来自用户生成的Tripo模型；其单一网格不直接拆改，新增入口几何作为独立场景对象挂在归一化建筑上。

`src/scene/cafe-state.ts` 提供 `createCafeState(surfaces)`：

- `group` 挂入咖啡馆建筑锚点；木材使用现有imagegen纹理。
- `setEntrance(bounds)` 接收同一局部坐标的归一化模型包围盒，将入口放到实际前沿外0.25米，沿用地标退距留下的净空。
- `update(opened, delta, reducedMotion)` 根据只读开张状态开合双扇木栅、切换中文营业牌、点亮两个实体门灯；减少动画时直接显示最终状态，不改金币、回合和证据。
- `dispose()` 仅释放本模块的几何、材质和文字贴图，保留共享木材纹理，可重复调用。

中文牌由真实画布文字生成，筹备时“咖啡馆筹备中／期待与你见面”，开张时“咖啡馆开张／欢迎光临”。没有用生成图片中的错误文字代替实际信息。开合入口、门柱和灯笼是真实几何，告示不是整栋建筑平面替身。

类型检查通过；几何检查已核对局部前沿定位、开关最终状态、有限包围盒与重复释放。接入、迎宾角色、实际镜头中的入口位置和道路净空仍须在运行图中核对；本模块单独交付不代表T12开张演出完成。
