## 2. 游戏主线与交互边界

玩家是一名参加小镇交易节的商人，初始现金1000枚小镇币。唯一表层目标是通过经营商品让账户资产增长；学习线是从看行情、做买卖，逐步形成一条可表达的办法，并在结算后去 PandaAI 继续验证。

推荐体验5–8分钟，是内容节奏而非强制计时或轮数。保留掷骰自动行走、岔路、跟随与全局视角、不同店铺的独立商品、买入/加仓/持有/卖出、连续资金和持仓。没有固定八轮终局；右上角设置随时结算，打开设置暂停移动。历史样本末尾明确提示并仍可结算。

教学按实际到达和已发生的行为推进，不要求固定店铺顺序或逛完八店。每轮只有一次主要交易决定。每个知识点首次出现时给一个可点开的短提示，后续保留轻量标记。

商品映射以 `src/trading/products.ts` 为唯一来源。当前八种为面包、木材、水果、芯片、金券、花束、咖啡豆、茶叶。户外点沿现有映射提供交易机会。

## 4. 通过游玩学习

围绕“行情事实 → 我的决定 → 现金/持仓变化 → 下一期盈亏”建立完整反馈：

- 交易前显示实际可成交数量、含费支出或净得现金、交易后现金和数量预览。
- 成交后将商品图标、数量增减、现金前后值和真实成交点对应起来。
- 下一期显示已有持仓随价格变化的金额。所选商品变化与全部持仓变化分别标清。
- 平均持仓成本含买入费用；卖出按实际比例释放成本，已实现和未实现盈亏分开。
- 当前持仓为0时不画成本线。图中金色虚线仅表示当前平均持仓成本。

固定手算核对例：1000现金，100买2份，费用0.1%，现金799.80、成本200.20；下一期95时，持仓市值190、总资产989.80、未实现盈亏-10.20。

让玩家用三项选择表达办法：“什么时候买／投入多少／什么时候退出”。例如站上均线买、最多半仓、跌回均线退出。玩家仍可手动决定；保存明确选定的规则与真实行动，不能把一次买入推断成他长期采用的策略。

加入两次短小且可跳过的知识互动：
1. 帮店员挂价格牌：识别K线实体两端的开盘、收盘。
2. 帮学徒判断：已选规则在当前已知图表中是否触发。
只把这些具有独立正确答案的互动记作相应知识证据。游戏赚钱或主动看过资料本身不等于掌握知识。

一局重点解释K线、均线、仓位、费用、浮动盈亏和回撤。EMA、MACD、RSI、KDJ、布林带、ATR放在可切换的研究视图，一次最多展开一种辅助指标。名称、公式、周期、预热和边界需核实。

## 5. 增加游戏趣味

用现有商品图和角色动作体现进货、背包持货和交货。岔路提前显示已知商品图标和已观察行情特点，让选路服务玩家的交易意图。

使用一位公开固定规则的电脑商人做对照。与玩家使用相同已知行情、同等交易机会与费用约束；比较起点一致，不得偷看未来或拥有玩家没有的资金。若中途开始对照，明确起始时点和相同账户起点。

表现行情的故事包装来自当前真实数据。市场路径在开局前确定，不因玩家选择临时制造惩罚、奖励或保证盈利。

## 6. 真实图表与数据

先检查现有历史导入是否保留真实最高价、最低价。目前本轮读取的报价类型只有开盘、收盘和成交量；如仍如此，须从已核验原CSV补齐开高低收后绘制K线，不能根据开收盘随机编影线。

同一商品的开高低收采用相同归一化比例，延续来源、校验值和许可说明。只暴露已知前缀，坐标范围、指标、信号和提示均不能读取未来。

均线、前高突破、成交量比较的窗口和时点口径应明确。当前已有“此前均价排除当期”约定，变更时要同步显示名称、计算、测试与文档。预热不足显示不足，必要时向玩法起点之前补真实历史。

纸上模拟的成交时点应一致。当期收盘信号不能倒回当期开盘成交。真实市场撮合能力、自动条件单等只按已实现范围表述。

## 8. 结算与简单PandaAI引导

结果主屏只突出：
- 实际总资产、盈亏、最大回撤。
- 玩家明确选定的办法，或“本局手动交易”。
- 两三项有证据的交易/学习事实。
- 一个与本局经历有关、值得继续验证的问题。

问题可随本局事实变化：
- 上涨后买入又回落：“为什么跟着上涨买，也会亏？”
- 频繁改变条件：“固定规则后，会有什么不同？”
- 交易多且费用增加：“少交易几次，会不会更好？”
- 规则盈利：“换段行情，还有效吗？”

主按钮“去 PandaAI 验证 ↗”只做普通网页跳转：
https://www.pandaaiquant.com/agent_quant/

小按钮“复制我的问题”由玩家主动复制本局规则、关键事实和问题，再自行粘贴。复制失败准确反馈，不声称已发送。保留查看依据、重开与清除；普通跳转不自动传递画像。

PandaAI画像关注明确选择的规则、真实资金占用、交易次数和机会、主动查看、客观小互动结果及下一步研究需求。每项可追溯到当时已知信息和实际机会，样本不足如实显示。随机落点不当兴趣，盈亏不当能力分数，不生成缺乏依据的人格标签。

示例复制内容：
“我完成了Panda Town模拟游戏，选择站上20期均线买、最多半仓、跌回均线退出。〔填实际交易与回撤〕。请把办法写成可回测规则，在你支持的股票或ETF教学标的上与买入持有比较，计入费用，解释它在上涨和震荡中的区别。这是游戏记录，不是真实投资资料。”

小镇商品是历史金融产品的游戏映射，不是真实证券代码。迁移到PandaAI的是规则与研究问题，不冒充原商品已经由PandaAI实盘验证。
