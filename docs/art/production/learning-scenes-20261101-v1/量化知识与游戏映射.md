# 量化知识与游戏内容映射

这是开发时的知识内容依据。目标是让玩家在观察、决定和后果之间理解概念，并把值得验证的规则带到PandaAI。主线少字；完整解释放在可点开的资料和研究视图中。

## 内容层次与完成要求

- 主线必学：K线、量价、均线与触发条件、仓位、费用与成本、浮动/已实现盈亏、回撤、把操作写成规则。
- 可选研究视图必须实际可切换：EMA、MACD、RSI、KDJ、布林带、ATR。每项有真实计算图形、一句解释、当前状态及适当的游戏情境，不能只做名词标签。
- 延伸研究卡：订单与流动性、因子与策略、回测与偏差、风险收益指标。用短例子解释，再形成PandaAI研究问题；不扩大为复杂交易终端。
- 看过资料、采用规则、在客观小互动中答对、在新情境中正确应用是不同证据。仅根据实际发生的证据表述，不把浏览次数换成知识分数。

## 一、行情图形与技术分析

| 知识 | 玩家能看懂的解释 | 游戏操作与反馈 | 学习证据 |
| --- | --- | --- | --- |
| 开盘、最高、最低、收盘 | 一根K线记录一个完整周期的四个价格 | 点按K线，图例与四个实际数值对应 | 在价格牌互动中正确定位开盘/收盘 |
| 实体、上下影线、阴阳线 | 实体连接开收盘，影线延伸至周期高低价 | 首次进货时高亮一根K线；颜色同时配文字方向 | 新商品上仍能辨认实体与影线 |
| 分钟K、日K、周K | 每根K线代表的时间长度不同 | 清楚显示当前频率；没有其他频率数据时不展示假切换 | 能判断当前一根代表一天还是一分钟 |
| 价格折线与K线 | 折线可只连收盘，K线多展示期间价格范围 | 主图切换时保持同一数据、日期与当前价格 | 识别两图显示信息的差别 |
| 成交量、成交额 | 成交数量与成交金额不同 | 水果集市量柱和K线对齐；单位标清 | 能从图上定位量明显增加的周期 |
| 放量、缩量 | 当前数量相对明确参考期变大或变小 | 对比此前均量，标“量比”及取样窗口 | 根据已知量柱判断变化，不要求预测涨跌 |
| 均线MA | 将指定窗口内价格平均，帮助观察趋势 | 木材铺把现价与参考均价画在同一主图 | 判断价格在参考线的上方或下方 |
| 指数移动平均线EMA | 对较新价格赋更高权重 | 与简单均线切换/对照，观察响应差别 | 识别较快响应；不记忆公式也可完成主线 |
| 向上突破、向下跌破 | 价格穿越明确的参考位置 | 芯片店标此前高点、均线与当期价格 | 根据已明示条件判断是否触发 |
| 金叉、死叉 | 指定快线向上/向下穿越慢线 | 指标研究视图对交叉点作轻量标记 | 判断已发生的交叉方向 |
| 多头、空头排列 | 短中长期均线形成不同顺序 | 多均线视图按清楚图例观察，不堆叠长说明 | 识别指定顺序；不直接记成买卖答案 |
| 顶背离、底背离 | 价格与指定指标未同步创新高/新低 | 点按高低点对照；先明确比较的两个时点 | 判断是否同步；不将背离当必然反转 |
| 十字星、锤子线、吞没形态 | 根据实体、影线及相邻K线关系命名的形态 | 可选形态资料中高亮所需K线 | 只核对形态条件，不考后续一定涨跌 |
| 支撑、阻力 | 从既往价格行为定义的参考区域 | 参考线/区域按已说明窗口计算 | 能解释突破的是哪个已知参考位置 |

K线无法还原一个周期内高低价出现的先后顺序。蜡烛的阴阳通常比较当期开盘和收盘，日涨跌幅则可能比较前一日收盘，两者不能混同。颜色统一并带图例，不只靠红绿。

均线必须有明确口径。若采用截至当期的20个收盘，标MA20；沿用现有排除当期的20期均价时，标“此前20期均价”。突破此前高点的参考窗口排除当期。图例、触发判断、说明和测试保持一致。

## 二、可选指标的真实交互

| 指标 | 一句话内容 | 游戏情境与交互 | 容易教错的地方 |
| --- | --- | --- | --- |
| EMA | “近期价格，权重更高” | 木材铺研究视图与简单均线切换，观察同一段行情的差别 | 明确初始化与预热；不能随手平滑一条线冒充指标 |
| MACD：指数平滑异同移动平均线 | “观察快慢均线差及动量变化” | 研究视图显示差值线、信号线和围绕零轴的柱；点按真实交叉，决定是否加入自己的规则 | 说明所用参数及柱体缩放，不能把交叉宣称为必涨必跌 |
| RSI：相对强弱指数 | “近期上涨与下跌，相对有多强” | 在震荡与趋势例子中切换；70/30可作明确的常用参考线 | 超买/超卖是指标状态，不等于马上反转；处理连续上涨、全平等边界 |
| KDJ：随机指标 | “收盘处在近期高低区间的哪里” | K、D、J三线与对应窗口展示，点按交叉查看 | KDJ里的K曲线不是蜡烛K线；J可能超出0至100 |
| 布林带 | “价格相对均线和波动范围的位置” | 显示中轨、上轨、下轨；点按带宽变化与触轨 | 触上轨不等于必须卖，触下轨不等于必须买；窗口和标准差口径明确 |
| ATR：平均真实波幅 | “考虑跳空在内的价格波动幅度” | 比较不同商品的实际波幅；在风险资料中解释为何固定金额波动不能直接等同风险 | ATR是价格单位的幅度，不能当收益率波动或方向预测 |

研究抽屉一次只展开一种辅助指标。每项提供：简短中文名、图例、数据窗口、当前数值/不足、一个短解释和“用于我的规则”入口。玩家没有明确选择时，不把查看当成采用。

至少实现一条完整指标体验：查看MACD真实图形 → 点按一处已经发生的交叉 → 看到一句解释 → 决定是否加入规则 → 后续新行情里判断该规则是否触发。其他指标沿用相同交互结构，避免每个指标另做一套课程页面。

## 三、交易、账户与执行

| 知识 | 在游戏中的表达 | 可观察的后果 |
| --- | --- | --- |
| 交易标的、持仓 | 店铺商品是交易对象，背包数量是当前持仓 | 商品、报价、数量和成交记录对应同一对象 |
| 建仓、加仓、减仓、平仓 | 首买、继续买、部分卖、全部卖 | 按实际数量改变背包、现金与成本 |
| 仓位 | 投入该资产或全部持仓的比例 | 预算选择先预览，成交后显示真实比例 |
| 做多、做空 | 持有商品的收益随价格变化；卖掉自有商品是减仓/平仓 | 当前现货式游戏没有做空执行时，仅在延伸卡解释区别 |
| 止损、止盈 | 盈亏达到预设退出条件的规则 | 没设条件单时，记录手动退出事实；不宣称自动触发 |
| 费用、滑点 | 成交成本和预期/实际成交价差 | 费用进入真实账本；未实现滑点模型时如实说明纸上成交假设 |
| 市价单、限价单 | 尽快成交与价格约束是不同要求 | 延伸卡比较“成交价格不保证”和“成交不保证”，不伪造当前游戏支持复杂订单 |
| 买卖价差、流动性 | 买卖报价不同；数量影响能否较快成交 | 用小图例说明，当前日线成交量上限不冒充真实盘口 |
| 浮动盈亏、已实现盈亏 | 未卖出的估值变化与已退出部分的结果 | 现价、含费成本、数量与卖出净款可追溯 |
| 现金、持仓市值、总资产 | 总资产由现金与当前持仓估值组成 | 移动到下一期时没有交易也可能变化 |

止损规则需要明确触发与成交时点，不能保证恰好按止损线价格成交。图上仅有一个周期高低价时，不知道止盈与止损谁先发生；本轮若不实现这类撮合，就保持玩家手动决定和收盘纸上成交。

## 四、策略、研究与风险收益

| 知识 | 游戏里怎样建立理解 | 继续交给PandaAI的问题 |
| --- | --- | --- |
| 信号、规则 | 把入场、仓位、退出写清，再看当前是否满足 | “把我的办法写成可回测策略” |
| 因子 | 可计算的资产特征；与买卖规则不是同一个东西 | “用动量或低波动特征生成因子并检验” |
| 动量、趋势跟踪 | 关注强势延续或按趋势条件行动 | “这条规则在震荡时会怎样？” |
| 均值回归 | 明确依赖向某个均衡水平回归的假设 | “这种偏离之后，历史上真的更常回归吗？” |
| 资产配置、再平衡 | 已有比例会因涨跌变化，调整回目标是另一种决定 | “保持目标仓位与一直持有有什么区别？” |
| 对冲、套利 | 降低相关风险或利用价格关系的不同思路 | 作为延伸研究，当前单商品买卖不冒充已实现对冲/套利 |
| 收益率、基准 | 说明统计区间，和相同条件的比较对象对照 | “与买入持有相比怎样？” |
| 回撤、最大回撤 | 从此前总资产高点到后续低点的跌幅 | “什么时候承受了最大回撤，规则为何失效？” |
| 波动率 | 收益变化的波动程度，不代表涨跌方向 | “同样收益下，波动有什么不同？” |
| 胜率、盈亏比 | 赢的次数与每次平均盈亏共同影响结果 | “高胜率为什么仍可能亏？” |
| 夏普比率 | 用一致口径衡量超额收益相对于波动 | 样本不足时不在5分钟游戏硬算能力分数，转向充分历史研究 |
| 阿尔法、贝塔 | 相对指定风险模型的收益与市场敏感程度 | “收益来自规则本身，还是市场整体上涨？” |
| 回测 | 把明确规则放到历史数据上按约定模拟执行 | “计入费用后再验证，并说明成交假设” |
| 样本内、样本外 | 开发规则的数据与未参与开发的检验数据分开 | “固定规则后，换未用过的区间验证” |
| 过拟合 | 对旧数据调得太贴，换数据可能失效 | “不要只挑最好参数，给出稳健性检验” |
| 前视偏差 | 使用了决策当时还不知道的信息 | “核对信号、数据发布时间与成交时点” |
| 模拟交易 | 用模拟资金验证，和真实资金交易分开 | “历史检验后，怎样用仿真继续观察？” |

游戏里换一处店或重玩已知时间段，可叫新情境练习或经验对照。只有规则先固定、随后数据真正未参与开发和选择时，才可声称样本外检验。参考图的漂亮曲线和某局盈利都不是策略有效性的证据。

## 五、玩家可见文案与画像

主屏短提示围绕当时已知事实：
- “站上均线”“跌回均线”“成交量放大”
- “还没卖，市值也会变”
- “这笔费用0.10”“等待，也是一种选择”
- “你的规则，现在触发了吗？”
- “换段行情，还有效吗？”

画像分清：
1. 玩家明确选择过的规则。
2. 实际买卖、资金占用与当时可用机会。
3. 主动查看过什么。
4. 客观小互动的结果及发生情境。
5. 当前想继续研究的问题。

浏览资料只记主动查看，答对一题只记该题/情境；一次盈亏不推定能力或人格。没有遇到、没有查看、没有测试的知识如实保留未观察状态。

## 七、交互验收

- 至少两次短互动有独立正确答案，并覆盖一次新商品/新情境。
- 从一根K线、一次成交到下一期市值变化的解释能在真实数据下成立。
- 所有研究指标有真实计算、预热不足与必要边界处理。
- 指标、知识提示与玩家规则使用同一时间口径和已知数据边界。
- 玩家在设置结算时，即使知识尚未覆盖，也能得到准确的已观察事实与下一步研究问题。
- 直接看完名词表不算完成以上验收。
