# 咖啡馆开张的三维状态

咖啡馆使用既有生成模型，不拆改其单体网格。额外木栅门、中文营业牌及门灯由 `cafe-state.ts` 创建，挂到真实咖啡馆的地标组中；模型归一化后，以实际前沿 `bounds.max.z + 0.25` 确定入口位置。建筑退距变化时，入口随建筑移动，原先固定世界坐标的暖光也改为跟随入口。

筹备状态下，两扇实体栅门闭合，牌面显示“咖啡馆筹备中”，迎宾角色隐藏。开张状态使栅门分别旋转约正负99度，牌面变为“咖啡馆开张／欢迎光临”，门灯和入口暖光亮起，门右侧出现绿色围裙的迎宾熊猫。迎宾复用既有生成熊猫网格与独立骨骼，播放待机并对左上臂施加轻微关节招呼动作；未额外生成或请求另一份人物模型。

营业状态只读取真实 `cafeOpened`，不计算新经济规则、不改变领域落点。简化动画开启时栅门直接到目标角度、迎宾保留静态招呼姿态；重开后仍由新局的关闭状态恢复。门与迎宾放在建筑前侧和门侧，不占道路节点中央。

对象名 `CafeGateLeft`、`CafeGateRight`、`CafeBusinessSign` 和 `CafeWelcomeResident` 供运行检查定位。`data-cafe-opening` 取门的实际插值开合比例，`data-cafe-welcome` 取迎宾对象实际可见性。数值状态不能代替实物截图。

类型检查已通过；独立对象核验确认筹备关闭／迎宾隐藏、开张时门角度-1.728弧度／迎宾可见、重置后再次关闭隐藏。正式三维模型下的门侧空间、营业牌可读性和结算镜头仍等待生产运行对照，不能据此提前宣称视觉验收通过。
