# 三维环境制作记录

日期：2026-10-31。负责人：资产与设计 Agent。以 `../fairytale-town-reference.png` 和本目录 `town-overview.png` 为美术参考；它们是参考图，不是运行截图。

## 当前接入

- `src/scene/landscape.ts`：随街道高度过渡的真实网格地形、下切河槽、河岸岩石、可透视的石拱洞与桥栏、沿弯路铺设的独立石块、树冠与灌木花带、后景山岩。重复景物使用实例化渲染，不使用整镇平面图代替几何。
- `src/scene/architecture.ts`：木构灰泥建筑的真实山墙、斜屋面、窗框百叶、门洞、花箱及灯笼；研究站穹顶、银行柱廊、集市布篷及咖啡馆露台形成不同轮廓。作为六处自建地标及外部模型就绪前的占位，不能冒称 Tripo 产物。
- `src/scene/rendering.ts`：复用仓库已安装 Three.js 的后处理源码，桌面采用低采样屏幕空间环境光遮蔽，小屏直接渲染。没有新增运行依赖。暖色日光、冷色补光、环境光及远景雾共同形成层次。
- 四类 imagegen 纹理继续从 `/art/texture-*.png` 加载，分别用于木材、灰泥、屋瓦和布篷。模型加载后整体替换对应占位；共享纹理不随某个占位的替换而销毁。

## 本轮机械检查

TypeScript 全项目检查通过。场景中央处理器几何检查得到环境 61 个网格对象、4067 个实例，坐标全部有限；八处建筑包围盒非空。桥拱中心下方的横穿射线未命中桥体，验证拱洞是实际空隙。格式检查通过。无贴图的材质显式使用空贴图，避免数百条未定义参数警告。

同机 Node 环境的一次生成检查中，改用平方距离比较后，环境生成从约 3068 毫秒降至 457 毫秒；只在找到最近点后计算一次平方根。该结果仅说明生成阶段的开销，不代表浏览器运行帧率或实体设备性能验收。

以上检查不能证明真实渲染通过。当前子线程内置浏览器不可用，实际截图由拥有可控浏览器的主 Agent 补充；开发日志曾出现热更新后的运行错误提示，尚待实际画面确认原因。
