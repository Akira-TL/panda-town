# NPC角色模型生成包

本包为Panda Town的15名非玩家角色（Non-Player Character，NPC）分别准备单独的全身角色图。8名店铺角色与7名户外居民逐一对应当前场景；玩家角色不在本包内。

## 使用方法

1. 每次上传一张编号PNG原图，单独生成一个角色模型。不要把预览总览或HTML截图作为建模输入。
2. 模型导出为GLB并保留颜色、材质与贴图。建议按下表的模型文件名保存，便于后续逐一替换。
3. 生成好的GLB放到下载目录后告知；后续再统一调整尺寸、朝向、脚底高度和动画，并接入游戏。

所有图片由内置imagegen独立生成；完整提示词见 npc-prompts.md。透明背景保留在PNG中，不需要额外加入地面、背景或台座。
