# 地表材质的场景接入

三张已生成运行图应用于真实地形、道路和广场、石拱桥及地标台基。草泥每轮覆盖2米，鹅卵石1.4米，砌石2米；纹理采用 sRGB 颜色空间和重复采样。纹理原图与独立生成记录仍见本目录说明。

`ground-surfaces.ts` 从网格位置变换到世界坐标后生成纹理坐标；水平面投影到地面，侧面按法线选择竖直投影，因此道路长度、桥宽和台基尺寸变化不会把一幅图拉长覆盖整段。地标异步加载后重新调整台基，同时更新纹理坐标。图像未提供法线或粗糙度，继续用实体几何和统一光照表现起伏。

材质颜色改为白色，草地顶点色仅保留小幅宽缓变化及河岸浅冷色，避免与原深绿重复相乘。原道路五排箱形石块收为两侧较小边石，广场中心的规则大石块退到周边，露出生成的鹅卵石表面。地形、路线、河流及事件位置不变。

三图增加1,437,308字节请求。成功或失败沿现有资产状态上报为 `material-grass-earth`、`material-cobblestone-path`、`material-stone-wall`；组件销毁后不继续上报。纹理和几何按场景生命周期释放。

类型检查与世界坐标投影的有限值、尺度核验已经通过；地形大面积重复、银行与研究站台基的实际接地、双镜头色调仍等待接入后的生产截图，不把坐标核验当成美术完成。
