# 石墙、鹅卵石与草泥地表材质

这批素材用于补齐现有挡墙、道路和地形大面积纯色的视觉缺口。三张图均由内置 imagegen 独立生成，参考既有童话小镇与户外街区；完整输入和原始输出位置见 [prompts.md](prompts.md)。本目录保存原始 PNG，运行图放在 `public/art/materials/`。源码及场景接入不属于本次素材交付。

## 文件与尺度

所有原图实际为 1254×1254、RGB、不透明；运行副本均为 1024×1024、不透明 WebP。

| 稳定标识 | 原图字节 | 运行图字节 | 建议用途与起始尺度 |
| --- | ---: | ---: | --- |
| `stone-wall` | 3,634,926 | 419,690 | 暖米色不规则砌石挡墙；一轮重复约覆盖 2×2 米，石块多为中等尺度 |
| `cobblestone-path` | 4,043,365 | 468,216 | 浅色天然鹅卵石道路；一轮重复先取 1.2–1.5 米，较大石子不放大成整块路砖 |
| `grass-earth` | 4,220,676 | 549,402 | 草地、少量泥土和苔藓地表；一轮重复先取 2×2 米，再结合实际镜头核对细节密度 |

三张原图合计 11,898,967 字节，运行图合计 1,437,308 字节。实际使用地址分别是 `/art/materials/stone-wall.webp`、`/art/materials/cobblestone-path.webp`、`/art/materials/grass-earth.webp`。

尺度指世界空间的建议起点，不是把整幅图拉满任意大小的网格。接入方应按实际米数生成表面坐标，避免石子被拉长、挡墙纹理横向挤压或草叶放大；也应避免把现有深色材质再与彩图相乘，使地表重复染色。图片使用 `THREE.SRGBColorSpace` 读入，继续服从当前统一光照。

## 实际目视检查

`*-tiling-check.jpg` 是解码后的运行副本缩到 512 像素，再做 2×2 拼接；`*-seams-check.png` 是四个原尺寸边角拼成的 512×512 接缝交汇图。它们仅用于检查，不是场景背景、不是游戏资产，也不是运行截图。三张拼接图及三张接缝交汇图均已实际查看。

- 石墙：石块、砂浆在中央水平和垂直接边处未形成明显切断的直线；大小和朝向有变化，仍能识别整块纹理的周期性重复。没有大面积定向亮暗或投射阴影，石缝保留了较深的材料色阶。近景不应再叠加强烈暗缝效果。
- 鹅卵石：石子自然散排，未出现规则砖行；接缝交汇处没有明显十字边框。浅米色与灰色石子混合，较大的灰石会成为重复识别点，因此接入时不能把一轮纹理放大到一整段街道。
- 草泥地：原尺寸交汇处没有明显十字缝，泥土与草色过渡没有硬边。远看仍能辨认周期性的浓淡斑块；后续大地形须在真实镜头中核对重复频率和饱和度，不能把本次小拼接检查说成全场景无重复。

本轮没有看到统一方向的高光、投射阴影或从一侧到另一侧的照明渐变。三个文件只有颜色，不提供法线、粗糙度或环境遮蔽贴图；表面几何和当前光照继续负责真实形体与接地阴影。

编码报告还记录了边缘色差与内部相邻像素色差。这些数值帮助定位异常，不能代替上述目视检查，也不作为“无缝合格分”。实际挡墙、弯路、地形中的接缝、密度和色调仍待场景接入后验证。

## 可复现编码

使用 [encode_materials.py](encode_materials.py)，脚本声明 `Pillow==13.0.0`，通过项目已使用的 `uv` 执行：

```powershell
uv run docs/art/production/materials/encode_materials.py
```

参数为 RGB、1024×1024、LANCZOS 缩放，WebP `quality=90`、`method=6`、`exact=True`。原始 PNG 不修改；脚本遇到已存在运行文件会停止，避免覆盖当前产物。检测到非正方形或非不透明源图也会停止。重现结果时需先由负责人选择新的输出位置或明确替换，不能跳过保护覆盖已有素材。

[encoding-report.json](encoding-report.json) 由这次真实编码生成。检查拼图没有修改图像内容，也没有用镜像、融合或自动修补把接缝缺陷隐藏起来。
