# 整镇构图与环境层次调整

依据完整模型运行截图 `logs/scene-12ed86b/` 与 `town-overview.png` 对照，旧跟随机位从镇内看向外围空地，灰色天空、平草地及同形山石削弱了街巷。此次调整只涉及场景与摄影，不改变路线连接、停靠标识、骰子、账本或证据规则。

- 镜头以行进路线切线为依据选后方候选机位；初始沿广场通往面包店的方向构图，店前仍按建筑包围盒避挡。
- 天空使用原生画布绘制蓝天渐变；暖阳、天空环境光与冷色远景雾分别承担明暗与深度，未只提高曝光。
- 远山分为前后两层，有不同轮廓、岩面色层及雾化距离；增加有岩壁支撑的背景跌水。
- 中央新增贴合地形的铺石广场、小喷泉及水弧，减少完整街区中的空草地。公共广场不是新增可行走边，不消耗游戏步数。
- 北侧既有路线和地标抬高形成台阶层次；建筑台基厚度按实际地面计算，保持接地。主要停靠的平面位置和图连接不变。
- 缩小沿路圆灌木；工具台移到集市居民后侧并增加桌面支撑，避免与居民重叠或工具悬空。

类型及几何有限值检查通过。待新版本真实跟随、俯瞰、手机截图与道具近景检查后再记录效果；以上制作说明不能替代运行验收，也不据此宣称已达到参考画面。
