# 码头临水位置修复

原码头停靠点 `(23,0.3,5)` 距河道过远，与码头语义不符。现改为右岸 `(8.3,0.3,7.2)`；保留 `music → dock → gifts` 图连接、每边一步、事件标识与后果。

对真实河曲作 2000 段采样，在 `z≈7.2` 处河中心 `x≈3.9137`，按水面半宽 2.2 米，右岸约为 `x=6.1137`。对进入和离开码头的实际弯曲道路各采样 180 段，路中心至河中心的最小平面距离均约 4.2027 米；减去道路半宽 1.2 米及河面半宽 2.2 米后，仍有约 0.8027 米净距。路线保持在右岸，没有穿河或移到桥上。

码头实体由户外模块向西侧水面伸出，主体中心约在 `x=6.2`，以短栈道接回岸上停靠点；不能继续使用普通地标的向镇外偏移。坐标修复与户外物件装配分别提交，后续在相同生产版本核对栈台接岸、支路行走及手机画面。
