## 提示词要点

面向 PandaAI 的原创三维探索与经济决策游戏；同一张图展示熊猫身后的第三人称镜头和全局俯瞰镜头。没有棋盘格，没有规整方环；弯曲石板路、溪流、小桥、坡地与广场相连，建筑高度、朝向和轮廓错落。木构与灰泥房屋、弧形瓦顶、花草、咖啡店和面包店；温暖午后阳光、柔和接触阴影、具有笔触感的三维材质。商店和熊猫角色承载事件，不使用现有大富翁商标。
