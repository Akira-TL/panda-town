# 工作流角色与标签

| 角色 | GitHub 标签 | 用途 |
| --- | --- | --- |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可由 Agent 执行 |
| `bug` | `bug` | 缺陷 |
| `enhancement` | `enhancement` | 新功能或改进 |
| `needs-triage` | `needs-triage` | 待判断范围与优先级 |
| `needs-info` | `needs-info` | 待补充信息 |
| `ready-for-human` | `ready-for-human` | 需要人工操作或判断 |
| `wontfix` | `wontfix` | 不计划处理 |
| `wayfinder:map` | `wayfinder:map` | 决策探索总览 |
| `wayfinder:research` | `wayfinder:research` | 外部资料研究 |
| `wayfinder:prototype` | `wayfinder:prototype` | 原型验证 |
| `wayfinder:grilling` | `wayfinder:grilling` | 需求澄清 |
| `wayfinder:task` | `wayfinder:task` | 解除决策阻塞的任务 |

保留已有标签的颜色和说明，只创建缺失项。
