# 画像研究的候选依据

检索日期：2026-10-31。下列为已核验的原始研究或作者机构资料，尚未选定为游戏评分方案。

## 消费偏好

消费风格量表（Consumer Styles Inventory, CSI）由 Sproles 与 Kendall 提出，研究消费决策的八种风格特征，可用于讨论本游戏应该观察什么。论文依据不能直接证明自编剧情选项具有同等测量效度。

来源：[A Methodology for Profiling Consumers’ Decision-Making Styles](https://onlinelibrary.wiley.com/doi/10.1111/j.1745-6606.1986.tb00382.x)。

## 风险相关选择

领域特异性风险承担量表（Domain-Specific Risk-Taking Scale, DOSPERT）区分金融、健康与安全、娱乐、伦理和社会领域；金融领域还区分投资与赌博。这提示游戏应分别讨论不同场景中的风险选择，不能把所有冒险行为合成一个人格结论。

来源：[哥伦比亚商学院量表说明](https://business.columbia.edu/cds/research/research-tools/dospert-scale)。

## 一般人格特征

大五人格量表第二版（Big Five Inventory–2, BFI-2）包含五个宽泛维度及更具体的特质。作者页面说明其题项并非公有领域，商业使用需联系作者。此处将其作为框架研究来源，尚未决定复制题项。

来源：[伯克利人格实验室](https://www.ocf.berkeley.edu/~johnlab/bfi)。

国际人格题库（International Personality Item Pool, IPIP）允许商业和非商业使用，可作为后续题项与许可研究的候选来源。公开许可不等于把题项改写成游戏事件后仍保有原有信效度。

来源：[IPIP 使用许可](https://ipip.ori.org/newPermission.htm)、[大五因素题项与计分方向](https://ipip.ori.org/newBigFive5broadKey.htm)。

## 仍需回答

- 5–8 分钟内能观察哪些维度，哪些需要留待追加互动？
- 游戏中的策略、余额约束、随机结果与一般人格倾向怎样区分？
- 画像应显示连续维度、叙事描述还是类型，如何标明证据不足？
- 如何把不同场景的行为证据连到具体数据、工具或学习任务？

这些都是待决定的研究与设计问题，不把当前候选来源包装成已经验证的游戏测量方法。
