# Panda Town 运行说明

## 项目与代码库

- 项目名称：Panda Town（熊猫小镇）
- GitHub 代码库：https://github.com/Akira-TL/panda-town
- 本机试玩地址：http://127.0.0.1:3018/

获取仓库最新提交或收到的源码包后，在包含 `package.json` 的项目根目录执行以下命令。

## 环境要求

- Windows 10/11、macOS 或 Linux。
- Node.js 20.9 或更高版本，并安装随 Node.js 提供的 npm。
- Windows 需要安装 Git for Windows，并使用 Git Bash 执行下列命令；macOS 和 Linux 可使用终端。
- 使用支持 WebGL 的浏览器，推荐 Chrome 或 Microsoft Edge。
- 首次安装依赖需要联网；运行游戏不需要账号、API 密钥或 Panda Data 权限。

## 安装与启动

1. 获取最新源码并解压，进入包含 `package.json` 的项目根目录。
2. 在该目录打开 Git Bash 或终端，依次执行：

```bash
npm ci
PANDA_MODE=production npm run build
PANDA_MODE=production PORT=3018 bash scripts/start.sh
```

3. 浏览器打开 http://127.0.0.1:3018/ ，点击“开始小镇交易”。

如果 3018 端口被占用，可更换端口：

```bash
PANDA_MODE=production PORT=3019 bash scripts/start.sh
```

然后打开 http://127.0.0.1:3019/ 。地址中的 `127.0.0.1` 指启动服务的那台电脑。

## 停止服务

在项目根目录执行：

```bash
PANDA_MODE=production bash scripts/stop.sh
```

运行日志位于 `logs/production.log` 和 `logs/production-error.log`。如果画面空白，请先检查浏览器是否支持并启用了 WebGL，再查看上述日志。

## 游戏操作

- 掷骰后自动行走，遇到岔路时选择路线。
- 在不同店铺查看行情，并选择买入、加仓、持有或卖出；背包中的商品可以跨店卖出。
- 使用“跟随”和“全局”切换视角，拖动画面可旋转视角；右上角“设置”中可随时结算。
- 资料中可以查看指标、设置交易规则；结算页可打开 PandaAI，也可主动复制本局研究问题。

游戏使用模拟资金，交易和学习记录保存在当前浏览器标签页，不会自动发送到 PandaAI。行情是历史金融数据的游戏映射，未接入 Panda Data 或真实交易账户。
