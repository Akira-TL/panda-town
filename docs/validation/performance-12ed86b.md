# 完整模型场景的本机性能记录

2026-10-31，对隔离生产快照 `12ed86b` 实测。十类模型全部装载后再开始采样，包含熊猫、树、面包店、杂货铺、集市、研究站、银行、礼品店、对手店与咖啡馆。此记录是实现过程中的机械验证，不是独立验收。

## 环境与方法

- Windows，本机 Intel Core i7-10875H、16个逻辑处理器、约32 GB内存。
- 隔离的无界面 Edge 156.0.4314.50，图形渲染器为 ANGLE / NVIDIA GeForce RTX 2060 / Direct3D 11。
- 服务使用项目脚本从 `.next-production` 启动，地址 `http://127.0.0.1:3018`；没有Blender或素材加工进程并行运行。
- 桌面使用1440×900；移动布局使用同一台电脑的390×844视口，不能代替实体手机结果。
- 关闭简化动画，在至少60秒的浏览器动画帧采样中实际掷骰、工作、推进两天并切换全局/跟随镜头。记录相邻动画帧回调的间隔，不把该间隔解释为单个GPU任务耗时。

## 采样结果

| 项目 | 桌面视口 | 移动布局视口 |
| --- | ---: | ---: |
| 采样时长 | 60,005.7毫秒 | 60,005.4毫秒 |
| 帧间隔数量 | 8,473 | 8,582 |
| 中位帧间隔 | 6.9毫秒 | 6.9毫秒 |
| 第95百分位帧间隔 | 7.1毫秒 | 7.1毫秒 |
| 所见资源编码正文合计 | 29,122,162字节 | 12,105,430字节 |
| 未处理页面异常 | 0 | 0 |

本机桌面所测间隔小于60帧/秒对应的16.67毫秒；390像素布局仍由同一RTX 2060运行，只证明该布局在本机的运行情况。所见资源编码正文合计低于规格的40 MB首局目标，但记录只覆盖本次两天操作期间实际请求的资源，包含缓存命中资源的编码正文信息；它不是冷缓存首屏压缩传输量，也不证明所有延迟资源或15 MB首屏目标均已验收。

原始逐资源大小、浏览器、图形渲染器、已加载逻辑名及异常列表见[桌面记录](evidence/performance-12ed86b-desktop.json)与[移动布局记录](evidence/performance-12ed86b-mobile-viewport.json)。

## 连续重开

通过可见手记执行五次“重开一局→确认重开”，每次重新确认介绍后核对：本局标识变化、现金1000、证据为空，页面仅有一个三维画布。每次主动垃圾回收后用浏览器调试协议记录资源：

| 项目 | 初始 | 第五次重开后 | 变化 |
| --- | ---: | ---: | ---: |
| 文档节点 | 226 | 226 | 0 |
| 事件监听器 | 317 | 317 | 0 |
| JavaScript堆已用字节 | 15,359,164 | 15,898,588 | +539,424 |

六个观察点的节点和监听器均不增长，未处理页面异常为空。堆用量增加约0.54 MB，单凭五次采样无法判断其来源；该测量也不能直接证明GPU缓冲、材质和纹理已全部释放。原始六次观测见[重开资源记录](evidence/performance-12ed86b-restarts.json)。

对应测试 `tests/browser/performance.spec.ts` 三项通过，耗时2.4分钟；运行原始结果另存 `logs/playwright-performance-12ed86b-results.json`。仍需实体手机、冷缓存首屏传输及更长时间运行的测量，后续居民或道具等场景变更应按影响范围复测。
