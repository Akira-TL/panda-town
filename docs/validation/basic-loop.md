## 独立金额预期

四次工作及四次零收支：骰序列 `3,1,1,1,1,1,1,1`，选项依次为 `skip,keep,skip,decline,work,work,work,work`，分支均走主路。测试每次通过真实按钮掷骰，仅在掷骰处理期间固定随机输入，随后恢复。

| 路线 | 手算结算前现金 | 实际支付后余额 |
| --- | ---: | ---: |
| 四次工作、四次零收支 | 1000＋8×150＋4×250＝3200 | 200 |
| 八次工作 | 1000＋8×150＋8×250＝4200 | 1200 |
| 八次零收支、保留筹备 | 1000＋8×150＝2200，差800 | 2200，未扣开店款 |

`12ed86b` 的30项浏览器回归包含上述路径、重开与清除；该轮原始报告已原样保存在 [regression-12ed86b.json](evidence/basic-loop/regression-12ed86b.json)。40项单元测试、5项路径测试及分轮浏览器范围见[运行验证](local-validation.md)，不把不同快照结果相加为一次运行。

核心的幂等输入同时检查原对象不被修改：一次工作1000→1250，复制恢复后相同动作被拒绝，回合结算一次到1400，旧日结算不会再次加钱。终局只在 `settlement` 接受一次 `finish`，变现、达标判定与支付后进入 `report`。
