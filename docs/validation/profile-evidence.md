## 七项验收条件核对

1. 使用公共 `Evidence`，三个区块由同一份只读记录生成；验收记录明确标注，正式模式仅记录实际动作。
2. 卡片显示实际次数和可选机会数；原事件证据保留现金、资产、完整选项及可用性、已看资料和实际选择后果。
3. 跨情境概括按 `contextId` 去重。充分、不足、禁用和重复四组的可见计数已实际核对。
4. 投资比例取决策前现金，17项画像测试中的独立金额案例通过；界面直接显示该分母与比例。
5. 矛盾行为并列保留，两个方向均有原记录；不从财富、读速或未点击推断能力与人格。
6. 判断的引用从被使用的真实记录产生，测试检查每个引用都能找到证据卡；无对应记录显示未观察。
7. 已执行概念图、生成元素、真实界面、运行截图的对照，具体见下节。
