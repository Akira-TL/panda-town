| 重开与清除 | 中途打开手记：取消、Escape、确认重开、确认清除；连续五位各完成八天后确认清除 | 取消不改原局；重开产生新标识、1000现金、空证据；清除回开场，刷新仍无旧局 |
| 损坏与不兼容记录 | 旧版本/无效结构和无法解析的 `{` 两种存储输入，实际打开页面并重新开始 | 两项均显示“记录版本不兼容或内容损坏，请重新开始”，新局规则为2、现金1000、证据为空 |
| 存储不可用 | 浏览器拒绝读取和写入后，仍完成八回合、终局与报告；另模拟拒绝删除 | 内存玩法结算4200、开店后1200；无法保存和旧记录未删除分别准确提示，不虚报已清除 |
| 换人及网络 | 连续五位换人；另执行两次完整八回合及刷新、证据浏览、确认重开、确认清除，捕获外部HTTP请求 | 新局没有上一局证据；该次外部请求列表为空，无行为或画像发送 |

源码层面，清除会释放页面对当前局及派生报告的引用，卸载报告与弹窗；重开以新局标识重建手记。报告只读当前局证据，未保留可从界面重新打开的历史记录。浏览器拒绝删除时明确告知残留；不把仅返回开场冒称彻底删除。
