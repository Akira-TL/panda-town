## 双视图一致性与正式路线

街景、俯瞰、对话与开张图共享熊猫的圆润比例、绿色背包、赭金围巾、红陶瓦、浅色灰泥、木构、花草、溪流与桥梁；主要地标的视觉识别一致。街道以连续弯道和台阶组织，没有棋盘格或方环。

图片里有多条装饰街巷，不能逐边读出正式十六点和两个岔路。现有概念图没有稳定的节点标注，不能仅凭看到弯路就宣称每条街道连接已与正式路线一一一致。正式连接必须取自 [content.ts](../../src/game/content.ts) 的 `LOCATIONS` 与[事件目录](../design/event-catalog.md)，空间坐标取自 [geometry.ts](../../src/scene/geometry.ts)，不能由 imagegen 自行决定。

已定的主环为：小镇广场→面包店→杂货铺→公告牌→集市→研究站→小桥→银行→礼品店→对手小店→河岸观景点→咖啡馆→广场。

两条正式支路分别是：杂货铺→修理摊→花园→集市；小桥→音乐角→码头→礼品店。全图十六点、十八条有向边，只有杂货铺和小桥两个正式岔路。图上其他装饰小径不增加游戏分支。

因此，视觉方向与可辨地标已经有可用基准；“概念双视图中的街道连接和两处分支可明确对应”的部分仍需补定位标注或来源核对。本记录不拿 T22 的整镇最终完成度替代这一具体差异，也不否定其余已经具备的素材。

## 四类基础纹理的实际平铺检查

检查对象是已使用的1024像素WebP副本，原PNG和提示词仍保存在生产目录。[纹理提示词](../art/production/texture-prompts.md)记录四类用途，[运行编码报告](../art/production/runtime-image-report.json)记录原图、副本、尺寸与来源。

这次用 Pillow 13.0.0 将每张运行图缩至512像素，四份原样拼为1024×1024 JPEG，`quality=92`、`subsampling=0`；没有镜像、融合或接缝修补。以下四图均已实际查看，保存于本项目供复核。

| 材质与检查图 | 实际观察及使用约束 |
| --- | --- |
| [木材2×2](evidence/visual-baseline/wood-2x2.jpg) | 横向木纹连续，没有明显十字色带；深木结会周期重复。需要沿木构方向赋予表面坐标，不能用一张图拉满整栋建筑 |
| [灰泥2×2](evidence/visual-baseline/plaster-2x2.jpg) | 暖米色、颗粒和抹痕低对比，没有明显拼接直线；大面积仍能看出重复的明暗团块，不能宣称无限铺地无重复 |
| [屋瓦2×2](evidence/visual-baseline/roof-2x2.jpg) | 红陶瓦的错行和上下叠压方向清晰，图块边缘没有明显断开的整条边框；规则瓦片本身存在节律与叠压暗边。需保持屋顶坡向，不能把颜色图当作真实屋瓦几何 |
| [布篷2×2](evidence/visual-baseline/canvas-2x2.jpg) | 细密浅色织纹，接边未见明显宽缝；近距离能辨织纹相位与重复。缩远后的细纹是否闪烁需在实际材质使用时核对 |

这四图可以作为基础纹理使用。本次只确认上述检查尺度下的可用性，没有制造“无缝分数”，也没有用缩小的拼接图代替所有运行距离的观察。后增石墙、鹅卵石、草泥纹理及各自检查另见[地表材质包](../art/production/materials/README.md)，不把它们混作原四种素材。

## 用途、许可与六项验收结论

效果图只作视觉参考，不能整张贴作可玩的三维场景；原角色和建筑输入图用于建模，GLB才是模型。纹理、头像和独立图标可直接被真实材质或界面读取。正式正文、金额、次数、选择按钮与图表仍由真实界面组件生成。

来源记录明确哪些模型由用户在Tripo生成，哪些图由imagegen生成、哪些是Blender渲染衍生；第三方账号计划和许可状态仍按各自来源记录保留，不把项目源码MIT许可自动扩展为所有外部模型和图像的许可声明。
