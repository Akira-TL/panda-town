# 本地玩法与运行验证

本记录是当前实现过程中的确定性测试和浏览器自查，不是用户另开的独立验收。模型加载、玩法、画面对照与设备性能分别按实际证据说明，不把加载成功当作整套验收通过。

## 执行方式

当前验证服务为 `http://127.0.0.1:3018`，项目位于系统默认文档目录下的 `ChatGPT/大富翁`。生产构建与开发缓存隔离，先执行：

```sh
PANDA_MODE=production npm run build
PANDA_MODE=production PORT=3018 bash scripts/start.sh
npm test
npm run test:paths
npm run test:browser
```

关闭同一服务使用 `PANDA_MODE=production bash scripts/stop.sh`。当前生产快照为12ed86b，40项单元和5项路径通过；同一快照的40项浏览器用例分四轮全部通过，无失败/跳过/重试。下文保留历史快照的各轮记录，不将不同快照结果相加；后续尚未构建的居民/资产状态及标题上缘修复不在12ed运行证据中。

浏览器测试使用官方 Playwright 1.64.1 和系统 Edge 的隔离无账号上下文，不访问个人浏览器资料。报告在 logs/playwright-results.json，失败截图和追踪在 logs/playwright-artifacts。默认逐个执行，避免并发场景拖累结果。服务须保持同一轮代码稳定，其他任务热更新发生时应单独复查失败。

## 此前开发服务的环境失败

修正后的八次工作完整用例通过：八回合4200、支付后1200，第2天选择后刷新恢复、报告证据弹窗、新局标识变化且证据清空、再完成八天、清除后刷新不恢复旧局，以及无外部请求，合计约1.1分钟。自动操作时间不能代表观众体验时长。

随后同轮3200和3180用例都在开场水合之前失败，未进行玩法操作。失败追踪的网络记录显示 main-app.js 请求响应状态为-1，`response._failureText` 为 `net::ERR_NO_BUFFER_SPACE`，约45.6毫秒内失败；同页其他Next脚本200。该错误与此前工具报告的本机套接字缓冲不足一致。开发主脚本约7.2 MB，直接HTTP可返回，但不能因此声称浏览器一定能完成加载。

证据：logs/playwright-artifacts/gameplay-四次工作四次零收支的真实路线到3200/trace.zip；当轮结果为1通过、2环境失败、6未执行。另行最短截图测试也未完成开场，不能将水合等待画面作为三维场景截图。没有删除.next、重置网络或调整安全设置。

已通过的生产流程不抹去这些开发环境失败记录。实体手机、真实观众时长、最终完整模型性能预算、加载故障专项、全部素材许可与最终效果图对照仍按矩阵保留未完成。
