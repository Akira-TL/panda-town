## 六项指标与规则的明确边界

图形和规则共用 `src/trading/indicators.ts` 与 `src/trading/learning/rules.ts`，界面不计算另一套答案。
空值表示未预热，不能画成0或从未来补齐。以下阈值是本游戏公开条件，不是收益保证。

| 指标                                                                  | 计算与显示口径                                       | 明确采用后的入场判断                                         |
| --------------------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------ |
| 指数移动平均线（Exponential Moving Average, EMA）                     | 默认12期，以首个完整窗口均价初始化                   | 前收不高于前点EMA，今收高于今点EMA                           |
| 指数平滑异同移动平均线（Moving Average Convergence Divergence, MACD） | 12/26/9；差值线减信号线为柱，不乘2；完整值最早索引33 | 前点差值线不高于信号线，当前差值线高于信号线；还需前一有效点 |
| 相对强弱指数（Relative Strength Index, RSI）                          | 14期Wilder平滑，连续涨和全平按明确边界计算           | 从不高于30变为高于30                                         |
| 随机指标（KDJ）                                                       | 9/3/3，初始K/D为50；J可越出0–100                     | 前点K不高于D，当前K高于D                                     |
| 布林带                                                                | 20期、2倍总体标准差；中轨包含当期收盘                | 收盘从不高于中轨变为高于中轨                                 |
| 平均真实波幅（Average True Range, ATR）                               | 14期Wilder平滑，真实波幅包含跳空                     | ATR/收盘达到3%，仅是波动阈值，不表示上涨方向                 |

规则的其他选项为手动、收盘上穿此前20期均价、收盘突破此前20根最高价。
投入上限为25%、50%、75%；退出为手动、均价下穿或相对当前含费均价亏损达到5%。
主卡的当前条件反馈不会自动生成买卖指令，真实成交还受现金、持仓和当日数量约束。

## 两种客观互动如何记证据

1. `getKnowledgePrompt` 首先寻找截至当前的最近一根非平K线；当前题干问开盘价，选项取真实开/收盘值。
2. 首次提交由领域模块核对并冻结。`answerId=null` 表示跳过，`correct=null` 不计入答错。
3. 完成或跳过首题后，只有明确采用规则、到新商品或新日期、且有足够历史时才出现规则判断题。
4. 新题记录采用事件标识、完整规则、商品和日期索引；`transfer=true` 区分新情境事实。重复作答或刷新不增加正确次数。
5. 两类互动不扣钱、不奖钱、不推进行情、不消耗本轮交易机会；答后解释保持可读，玩家主动返回买卖。

`LearningState.events` 区分规则、指标和知识事件。每条都有本局、轮次、地点、商品和市场索引；
资料查看、图上标记、明确采用和答题分别记录，不能互相填补缺失事实。
`buildLearningSummary` 只汇总实际答案，跳过单列；没有答案显示知识未观察。

## 同条件商人、盈亏与复制内容

电脑商人公开固定政策：优先按固定商品顺序卖出收盘低于此前20期均价的已有持仓；
否则，当前店商品发生均价上穿时申请买至总持仓半仓。每轮最多一次主要行动，
与玩家共用交易引擎的0.1%费、现金、持仓和数量限制；数量不足时允许部分成交，不能伪称卖清。
商人只跟随玩家已经完成的主要行动，未决定的当前轮只估值，不提前多走一步。

账户曲线重放真实到达和成交，区分市价变化与扣费后变化。最大回撤从已观察账户峰值计算，
不拿商品日内高低价虚构玩家当日资产路线。随时结算按现金加持仓市值冻结，不自动平仓。

研究问题依次依据真实上涨后买入又回落、多次改规则、交易费用或明确规则等事实选择；
无交易且无规则时使用“如果先固定一条规则，会发生什么？”，不暗示已经做过数次买卖。
主动复制包含所选办法、实际总资产/盈亏/费用/回撤/交易数、客观互动事实及一个研究问题。
链接精确为 `https://www.pandaaiquant.com/agent_quant/`，普通新页跳转不附带数据；
复制文本需要玩家自行粘贴，尚未由PandaAI验证。
