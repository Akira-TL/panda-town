# 用户画像面板内容方案

状态：规划方案，未开发。用户于 2026-10-31 决定游戏结束直接展示画像面板，取消推荐任务、后续研究练习和外部跳转，同时接受趣味称号和本设备记录的默认方式。

## 面板要回答的问题

让玩家和现场评审看清：本局观察到了什么，这些线索如何描述用户，哪些事情还不知道。PandaAI 的价值展示集中于消费与交易偏好、信息使用习惯、可核验的知识表现、兴趣和一般人格线索。

以下是内容组织方案，不是新增心理学分类体系。具体事件到维度的映射继续在画像研究与设计问题中确定。

## 1. 顶部结果

- 熊猫形象与一个趣味称号，称号具体文案由 Agent 设计。
- 一句概括本局行为的描述，限定在本次游戏观察内。
- 咖啡馆开张或筹备中，以及最终现金与资产情况。
- 单独说明开店结果，不把财富高低直接换算为人格优劣或交易能力。

## 2. 偏好与习惯

| 内容 | 面板拟展示的信息 | 需要回看的证据 |
| --- | --- | --- |
| 消费偏好 | 对价格、品质、新奇物品与保留现金的取舍 | 当时价格、余额、可买选项、实际选择 |
| 交易与经营偏好 | 确定收入与不确定收益的取舍、投入规模、行情变化后的行动 | 可见盈亏条件、投入占可用资金的比例、持有或退出选择 |
| 信息使用习惯 | 是否查看资料、比较来源、根据新信息调整选择 | 展开的资料、比较动作与前后决策，不将阅读速度直接当作能力 |
| 兴趣线索 | 主动查看或多次选择的经营、消费或数据主题 | 用户有选择机会时的自主行动；随机落点不计为兴趣 |
| 知识表现 | 仅在存在明确正确答案的事件中展示理解情况 | 原题、答案、评分依据；无对应事件则显示“本局未评估” |

不为画满图表而填入默认中间分。首版优先用短描述、可核对的行为次数和证据卡；尚无依据时显示未观察或信息不足，不显示伪精确的置信百分比。

## 3. 一般人格线索

与消费、交易偏好分区呈现。维度来源继续使用已有研究框架，游戏称号不替代正式维度。没有多情境支持的维度保留“线索不足”；不能因为玩家愿意合作就直接判断其现实中的宜人性，也不能因一次投资判断其整个人格。

矛盾证据可同时显示，例如早期保留现金、末期较大额投入，并说明可用资金和目标压力已经变化。具体判断规则尚待研究与事件设计核验。

## 4. 行为证据与不确定部分

每条判断可展开查看“场景 → 当时可见信息与资源约束 → 可选项 → 实际选择 → 支持的有限判断”。

面板同时列出未遇到的场景、被余额限制的选项、互相矛盾的选择和待进一步观察的内容。不能把没有出现的选项当作玩家主动拒绝。

## 5. 操作与数据

本局的产品流程为：三维游戏 → 咖啡馆结局 → 用户画像面板。

- 面板操作：展开证据、重开一局、清除记录。
- 无推荐列表、额外练习、课程入口、强制注册或外部跳转。
- 默认不登录，数据只在当前设备保存；具体存储方式在后续技术设计中确定。
- 清除操作覆盖本局行为和派生画像，不只隐藏画面。
- 公开展示不显示姓名、联系方式或账号；趣味称号不能包含身份信息。
- 不自动上传至开发者或 PandaAI；如未来收集反馈，须由玩家另外主动提交。

用户允许使用便于分享的趣味称号，不意味着已授权自动发布分享卡或上传原始行为。分享功能不作为当前必做范围。
