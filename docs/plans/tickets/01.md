# T01 — 生成整镇效果图与可用的基础素材包

状态：用户已授权实施，按来源规格和阻塞关系执行；完成证据齐备后才可关闭。

## 来源规格

[GitHub 来源规格](https://github.com/Akira-TL/panda-town/issues/10)；本地镜像见[首版产品规格](../../specs/panda-town.md)。各任务已建立原生子任务及阻塞关系，实际链接见任务索引。共同规则与验收接缝以来源规格为准。

## 交付行为

交付能逐张查看、可供后续场景直接使用的视觉基准；覆盖双视角、对话与画像面板。

## 阻塞任务

无，可开始。

## 负责范围与接入边界

整体风格基准、公共色彩与基础素材清单；不制作应用，不替代各街区的专属出图。

开始前核对阻塞产物、仓库状态和已有领取记录，依据实际协作技能确定文件所有权；本草案不冒充已经完成的任务领取。接口不足时回报具体需求及受影响任务，不能在本任务内复制第二套共同规则。

## 验收条件

- [ ] 读取 imagegen Skill，查看已选童话小镇图，以其为参考生成全局、街景、店前对话、咖啡馆开张、桌面与手机面板效果图。
- [ ] 双视角采用一致地标、屋顶色、街道连接和熊猫比例，包含弯曲路线与两处分支，不出现棋盘格。
- [ ] 依据效果图生成首批实际素材：熊猫头像、四类表面纹理及现金/资产/资料图标；透明素材检查真实透明通道。
- [ ] 素材可从项目内独立打开，记录提示词、参考关系、尺寸、来源、用途和许可状态。
- [ ] 明确哪些图片直接作游戏资产，哪些仅作建模参考；不把生成图片称作三维模型。
- [ ] 给出每张效果图的构图、光照及主要地标说明，局部美术任务可据此继续生成一致素材。

## 完成证据

六类效果图、基础素材实际文件、清单及视觉一致性检查。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
