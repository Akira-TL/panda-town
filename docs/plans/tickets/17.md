状态：用户已授权实施，按来源规格和阻塞关系执行；完成证据齐备后才可关闭。

## 来源规格

[首版产品规格](../../specs/panda-town.md)。发布时替换为确认后的 GitHub 规格 Issue 稳定链接，并设为其原生子任务。共同规则与验收接缝以来源规格为准。

## 交付行为

玩家刷新可继续当前局，重开和清除能让下一位参观者获得干净体验。

## 阻塞任务

- [T02](02.md)

## 负责范围与接入边界

会话存储与生命周期、恢复提示；不创建后台或历史用户库。

开始前核对阻塞产物、仓库状态和已有领取记录，依据实际协作技能确定文件所有权；本草案不冒充已经完成的任务领取。接口不足时回报具体需求及受影响任务，不能在本任务内复制第二套共同规则。

## 验收条件

- [ ] 只保存当前局与必要版本，刷新恢复位置、阶段、账本及证据，不重复提交未完成动作。
- [ ] 在移动、待选择、已提交待结算、报告四个阶段刷新，恢复到可解释状态。
- [ ] 重开生成新局并移除旧证据；清除同时清理存储、内存、派生画像并回到开场。
- [ ] 旧版本或损坏记录提示重新开始，不静默拼接新旧规则。
- [ ] 存储不可用仍可内存完成游戏，说明刷新会丢失；不会因此上传云端。
- [ ] 检查网络没有行为或画像发送，换人后无法从界面恢复前一局记录。

## 完成证据

四阶段恢复和重开/清除/存储失败的操作记录及网络检查。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
