## 验收条件

- [x] 只保存当前局与必要版本，刷新恢复位置、阶段、账本及证据，不重复提交未完成动作。
- [x] 在移动、待选择、已提交待结算、报告四个阶段刷新，恢复到可解释状态。
- [x] 重开生成新局并移除旧证据；清除同时清理存储、内存、派生画像并回到开场。
- [x] 旧版本或损坏记录提示重新开始，不静默拼接新旧规则。
- [x] 存储不可用仍可内存完成游戏，说明刷新会丢失；不会因此上传云端。
- [x] 检查网络没有行为或画像发送，换人后无法从界面恢复前一局记录。
