## 负责范围与接入边界

三个行为区块及证据卡内容单元；不改总体面板布局和一般人格规则。

开始前核对阻塞产物、仓库状态和已有领取记录，依据实际协作技能确定文件所有权；本草案不冒充已经完成的任务领取。接口不足时回报具体需求及受影响任务，不能在本任务内复制第二套共同规则。

## 验收条件

- [ ] 使用公共本局记录，通过实际操作或明确标注的验收记录呈现三类区块；正式模式不注入虚构经历。
- [ ] 展示选择次数及实际可选机会数，保留余额、可用性、已见信息与实际后果。
- [ ] 至少两个独立情境才使用多次倾向描述，单次列事实；未展示、禁用和重复展开均正确处理。
- [ ] 投入比例以决策当时可用现金为分母，不以结局余额替代。
- [ ] 矛盾行为并列可展开；不将财富、读得快或未点击资料判为能力或人格。
- [ ] 证据引用能定位原事件，不存在引用时拒绝生成该判断；空记录显示未观察。
- [ ] 执行[视觉生产流程](../../design/visual-production.md)：imagegen 效果图 → 生成并使用元素图 → 真实三维/界面 → 运行截图对照；提交对应证据。

## 完成证据

充分、不足、矛盾、禁用、重复五组记录的报告截图及独立预期。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
