- [x] 当前店买入受现金/手续费/当日量限制，保留请求和实际数量；空现金与无量不假成交。
- [x] 25%/50%/75%目标或份数控件按真实价格/费用算预览，目标与实际买后比例分开。
- [x] 交易前展示实际可成交量、含费支出、现金/持仓前后值，并清楚标为预览。
