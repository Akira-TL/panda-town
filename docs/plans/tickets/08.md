玩家读懂演示报价后投入小额资金，看到第四天与第八天变化，选择持有或出售。

## 验收条件

- [ ] 购买显示投入 200/400、当前报价、份额、费用为零与最大损失，余额不足时说明差额。
- [ ] 情境甲乙开局固定，报价按规格时机变化；同一输入不因选择变化而改行情。
- [ ] 第四天前不显示未来报价；到期公告不要求刚好走到银行。
- [ ] 只能一笔持仓，第八天不新买；出售全部份额、按规则舍入，重复出售无额外收益。
- [ ] 甲情境第一天投 200、第八天卖出到账 220，乙为 180；另核验第四天购入按当时报价计算份额。
- [ ] 现金、持仓、退出记录与可见图表一致，报告不把赚钱等同于能力强。
- [ ] 工作及不持仓的替代路径能继续八回合，资料查看不强迫购买。
- [ ] 执行[视觉生产流程](../../design/visual-production.md)：imagegen 效果图 → 生成并使用元素图 → 真实三维/界面 → 运行截图对照；提交对应证据。

## 完成证据

甲乙两条确定性投资路径、不能购买/重复出售情形、资料与账本对照。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
