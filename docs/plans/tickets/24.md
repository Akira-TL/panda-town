## 负责范围与接入边界

## 验收条件

- [ ] 从干净环境按项目脚本启动，走完工作/经营两条差异路径及一次未达标结果。
- [ ] 桌面、手机、键盘模式核对核心流程；记录实际测试设备与未验证条件。
- [ ] 记录真实体验时长分布或各次时长，阅读不限时；不足以支持 5–8 分钟时修正文案或明确待调。
- [ ] 连续五位模拟参观者重开/清除，前一局记录不进入后一局报告，无意外上传。
- [ ] 验收表逐项链接玩法、画像、视觉、性能和数据行为证据；未完成项保持未完成。
- [ ] 提供启动/停止、演示步骤、数据重置、已知限制与异常恢复说明，不部署或发布版本。
- [ ] 如要求独立 Agent 验收，提供包含项目路径、隔离读写边界、目标与门槛的完整提示词，交由用户新开会话执行。

## 完成证据

可直接使用的展会操作文档、全流程证据索引、剩余问题和可选独立验收提示词。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
