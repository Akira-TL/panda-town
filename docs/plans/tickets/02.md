## 验收条件

- [x] 核验并记录三维库兼容性，沿用已定技术栈；交付八回合完整路径，不只提供模型或状态函数。
- [x] 加载 T01 的实际生成素材，有真实熊猫形体、道路、日光与基本遮挡；第三人称可看清自动移动。
- [x] 开局目标、现金、回合、骰子、工作/观察和结算有可操作界面；第八回合进入基础证据面板。
- [x] 公共接口覆盖规格中的动作、阶段、经济效果、地点/事件标识、画像插槽与版本，提供每类插槽的最小使用样例。
- [x] 固定输入下四次工作与四次观察得到结算前 3200、支付开店成本后 200；重复点击不重复入账。
- [x] 公开公共数据形状、扩展方式及全局装配负责人，后续单元无需修改核心账本也能注册自己的效果。
- [x] 用项目规定脚本启动和停止，日志可检查；依赖安装和启动说明完整，基础资产从本地加载。
- [x] 执行[视觉生产流程](../../design/visual-production.md)：imagegen 效果图 → 生成并使用元素图 → 真实三维/界面 → 运行截图对照；提交对应证据。

## 完成证据

可运行的八回合演示、独立手算案例结果、接口说明及真实截图。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
