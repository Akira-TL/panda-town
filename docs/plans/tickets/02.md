# T02 — 打通一次八回合的最小游戏闭环

状态：用户已授权实施，按来源规格和阻塞关系执行；完成证据齐备后才可关闭。

## 来源规格

[首版产品规格](../../specs/panda-town.md)。发布时替换为确认后的 GitHub 规格 Issue 稳定链接，并设为其原生子任务。共同规则与验收接缝以来源规格为准。

## 交付行为

玩家在简化但真实的三维场景中开局、掷骰、自动移动、选择工作或观察、结算并看见本局证据。

## 负责范围与接入边界

公共动作与状态、经济账本、加载和场景/事件/画像插槽、最小交互外壳；后续任务通过插槽扩展。

开始前核对阻塞产物、仓库状态和已有领取记录，依据实际协作技能确定文件所有权；本草案不冒充已经完成的任务领取。接口不足时回报具体需求及受影响任务，不能在本任务内复制第二套共同规则。

## 验收条件

- [ ] 核验并记录三维库兼容性，沿用已定技术栈；交付八回合完整路径，不只提供模型或状态函数。
- [ ] 加载 T01 的实际生成素材，有真实熊猫形体、道路、日光与基本遮挡；第三人称可看清自动移动。
- [ ] 开局目标、现金、回合、骰子、工作/观察和结算有可操作界面；第八回合进入基础证据面板。
- [ ] 公共接口覆盖规格中的动作、阶段、经济效果、地点/事件标识、画像插槽与版本，提供每类插槽的最小使用样例。
- [ ] 固定输入下四次工作与四次观察得到结算前 3200、支付开店成本后 200；重复点击不重复入账。
- [ ] 公开公共数据形状、扩展方式及全局装配负责人，后续单元无需修改核心账本也能注册自己的效果。
- [ ] 用项目规定脚本启动和停止，日志可检查；依赖安装和启动说明完整，基础资产从本地加载。
- [ ] 执行[视觉生产流程](../../design/visual-production.md)：imagegen 效果图 → 生成并使用元素图 → 真实三维/界面 → 运行截图对照；提交对应证据。

## 完成证据

可运行的八回合演示、独立手算案例结果、接口说明及真实截图。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
