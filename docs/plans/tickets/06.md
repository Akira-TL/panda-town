## 交付行为

玩家从经过集市到买下摊位、看见招牌变化、领取收入并在终局出售，完成经营路径。

## 负责范围与接入边界

集市地标、E03、经营资产展示；不修改全局结算顺序。

开始前核对阻塞产物、仓库状态和已有领取记录，依据实际协作技能确定文件所有权；本草案不冒充已经完成的任务领取。接口不足时回报具体需求及受影响任务，不能在本任务内复制第二套共同规则。

## 验收条件

- [ ] 购买前显示 600 成本、次回合开始 +100、终局 480 退出和剩余回合。
- [ ] 购买后摊位招牌/货架可见变化，第三人称与全局显示同一所有权。
- [ ] 购买当回合不发经营收入，次回合起每回合只发一次。
- [ ] 最多一个摊位；重访改为经营状态与工作，不重复购买或赠送。
- [ ] 终局可以出售或保留，出售现金 +480 并移除经营资产，保留则不计作现金。
- [ ] 独立验收第二天购买、无工具、两次工作得到 3180；工具效果通过已定公共契约接入。
- [ ] 执行[视觉生产流程](../../design/visual-production.md)：imagegen 效果图 → 生成并使用元素图 → 真实三维/界面 → 运行截图对照；提交对应证据。

## 完成证据

从购买到终局的账目与场景变化，保留/出售对照。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
