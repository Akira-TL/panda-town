## 负责范围与接入边界

全局视觉整合、光照与镜头调优、跨地区接缝；不接手未交付的地区模型或重写画像。

开始前核对阻塞产物、仓库状态和已有领取记录，依据实际协作技能确定文件所有权；本草案不冒充已经完成的任务领取。接口不足时回报具体需求及受影响任务，不能在本任务内复制第二套共同规则。

## 验收条件

- [ ] 逐项核对全部主要地标、弯路、支路、熊猫比例、建筑错落、材质及光照与参考图差异。
- [ ] 同一地点第三人称和俯瞰真实截图可对应，无贴片背面消失或单视角伪立体。
- [ ] 修复道路穿模、相邻建筑接缝、遮挡招牌/人物和公共光照不一致。
- [ ] 桌面与手机的对话、结算、报告使用实际素材且清晰可操作，减少动画模式也完整。
- [ ] 保存参考图与运行截图成组证据，逐条列出修复和有理由保留的取舍。
- [ ] 生成素材清单可追到每个实际使用处，缺的效果图或元素图退回对应任务补齐，不用笼统的美化完成代替。
- [ ] 执行[视觉生产流程](../../design/visual-production.md)：imagegen 效果图 → 生成并使用元素图 → 真实三维/界面 → 运行截图对照；提交对应证据。

## 完成证据

全局、街景、两种结局、对话和报告的双设备对照图及差异清单。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
