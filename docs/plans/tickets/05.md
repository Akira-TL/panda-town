## 负责范围与接入边界

杂货铺地标、E02 工具内容与效果声明；不实现集市主流程或改账本。

开始前核对阻塞产物、仓库状态和已有领取记录，依据实际协作技能确定文件所有权；本草案不冒充已经完成的任务领取。接口不足时回报具体需求及受影响任务，不能在本任务内复制第二套共同规则。

## 验收条件

- [ ] 两种工具有独立生成物件图和实际场景展示，杂货铺可从门廊货箱辨认。
- [ ] 确认前说明 100/180 成本、每次经营收入 +20/+40、剩余天数和没有摊位时的含义。
- [ ] 只能拥有一种工具；不可通过重复购买、刷新、重访叠加加成。
- [ ] 余额不足禁用并记录约束；工作仍可选。
- [ ] 通过公共接口注入已有摊位的验收局，观察下一次真实回合结算分别到账 120/140；使用独立预期。
- [ ] 购买与未来到账分别记证据，面板不把工具价高直接写成品质人格。
- [ ] 执行[视觉生产流程](../../design/visual-production.md)：imagegen 效果图 → 生成并使用元素图 → 真实三维/界面 → 运行截图对照；提交对应证据。

## 完成证据

无摊位购买、有摊位到账、重复购买阻止三种完整操作记录。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
