## 验收条件

- [x] 题干、选项、可见资料与正确答案按目录一致，分别检验读数和事实辨别。
- [x] 可跳过，不影响现金、主要事件或开店资格。
- [x] 首次提交后显示解释；重复查看或改答不能增加正确题数或独立题数。
- [x] 记录原题、用户答案、评分依据及是否已揭示答案。
- [x] 未遇题/全跳过显示未评估，答一题的分母为一；不换算综合金融能力。
- [x] 交付可由 T07/T10 接入的独立题目区域和报告插槽，用公共回合演示验证。
- [x] 执行[视觉生产流程](../../design/visual-production.md)：imagegen 效果图 → 生成并使用元素图 → 真实三维/界面 → 运行截图对照；提交对应证据。

## 完成证据

正确、错误、跳过、重复答题四条操作结果及知识面板。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
