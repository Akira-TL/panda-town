## 验收条件

- [ ] 按规格与事件目录只输出有证据的行为线索，每条都能展开其情境。
- [ ] 不同地点的同一事件变体不能冒充两个独立情境，随机落点不作主动兴趣。
- [ ] 一般人格不足维度可全部显示不足；情绪稳定性明确未评估，无默认中间分或百分比。
- [ ] 合作折扣、投资盈亏和余额限制不能直接映射人格特征。
- [ ] 三个称号及优先级严格对应已定规则，说明触发依据；无证据使用默认称号。
- [ ] 相反证据同时显示，不隐藏；称号变化不会改变经济规则或对手策略。
- [ ] 执行[视觉生产流程](../../design/visual-production.md)：imagegen 效果图 → 生成并使用元素图 → 真实三维/界面 → 运行截图对照；提交对应证据。

## 完成证据

默认、两个称号、矛盾人格线索、同事件变体四类以上样例结果。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
