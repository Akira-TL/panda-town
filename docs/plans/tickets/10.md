# T10 — 户外居民互动与消息核对

状态：用户已授权实施，按来源规格和阻塞关系执行；完成证据齐备后才可关闭。

## 来源规格

[GitHub 来源规格](https://github.com/Akira-TL/panda-town/issues/10)；本地镜像见[首版产品规格](../../specs/panda-town.md)。各任务已建立原生子任务及阻塞关系，实际链接见任务索引。共同规则与验收接缝以来源规格为准。

## 交付行为

玩家在修理摊、花园、音乐角和码头完成帮忙、交谈或核对消息，选择进入本局证据。

## 阻塞任务

- [T03](03.md)

## 负责范围与接入边界

四个户外支路点及 E09/E10/E11；复用公共角色形体，不改道路连接。

开始前核对阻塞产物、仓库状态和已有领取记录，依据实际协作技能确定文件所有权；本草案不冒充已经完成的任务领取。接口不足时回报具体需求及受影响任务，不能在本任务内复制第二套共同规则。

## 验收条件

- [ ] 四点分别有维修道具、花园座位、音乐道具、码头货箱，空间布局不遮挡主路。
- [ ] E09 免费帮忙或付 60 找师傅均有明确结果，工作另列；无额外隐藏奖励。
- [ ] E10 主动交谈与独自观赏有不同回应，地点变体仍归同一基础情境。
- [ ] E11 两份消息带演示来源与日期，核对动作有证据；预留 K02 插入位置。
- [ ] 随机经过不记录为兴趣，重复音乐角/花园互动不伪造多情境人格证据。
- [ ] 每个点均可在完整回合内触发、选择、结束并恢复移动，不只是静态装饰。
- [ ] 执行[视觉生产流程](../../design/visual-production.md)：imagegen 效果图 → 生成并使用元素图 → 真实三维/界面 → 运行截图对照；提交对应证据。

## 完成证据

四点各一条完整交互，至少一组重复情境证据检查及支路截图。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
