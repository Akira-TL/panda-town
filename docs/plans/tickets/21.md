## 验收条件

- [ ] 十六地点与十二基础事件全部接入，地点、条件、变体、回退及工作选项符合目录。
- [ ] 任何落点都有可完成的主要事件；没有合格主题时使用盘点转述，不空弹窗或卡回合。
- [ ] 第 1/4/8 天信息按时出现，第四天和第八天报价在决策前更新，对手和收入各只推进一次。
- [ ] 研究站 K01 与码头 K02 接入真实资料入口，跳过不阻塞主线。
- [ ] 工具、摊位、投资、合作延迟交货与终局按共同规则交互，刷新后仍一致。
- [ ] 每局八个主要事件；路过、资料展开与公告不额外占行动；随机性不暗改。
- [ ] 完整局的记录能交给画像插槽，缺失内容显示未观察，真实体验不塞验收样例。
