## 验收条件

- [ ] 结果、称号、消费交易、信息、兴趣、知识、一般人格和未观察部分均有位置，空状态不填伪数据。
- [ ] 开店前现金、开店后余额、保留资产和缺口按实际结局显示，不混淆。
- [ ] 一条判断可展开到来源情境并返回原阅读位置，长证据不会遮住关闭或操作按钮。
- [ ] 主界面只保留证据、重开、清除，不增加推荐、课程、注册、外跳或上传。
- [ ] 使用效果图生成的头像、图标和装饰，但正文、金额、图表与按钮是真实界面元素。
- [ ] 证据引用完整；缺少子区块数据时展示未观察而不是崩溃。
- [ ] 执行[视觉生产流程](../../design/visual-production.md)：imagegen 效果图 → 生成并使用元素图 → 真实三维/界面 → 运行截图对照；提交对应证据。

## 完成证据

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
