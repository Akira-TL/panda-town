# T11 — 电脑对手经营与合作采购

状态：用户已授权实施，按来源规格和阻塞关系执行；完成证据齐备后才可关闭。

## 来源规格

[首版产品规格](../../specs/panda-town.md)。发布时替换为确认后的 GitHub 规格 Issue 稳定链接，并设为其原生子任务。共同规则与验收接缝以来源规格为准。

## 交付行为

玩家看见对手自己的经营进展，接受或拒绝一次采购合作后继续自己的八回合。

## 阻塞任务

- [T03](03.md)

## 负责范围与接入边界

对手角色与小店、独立账本、E08；不改玩家的基础收入和胜利条件。

开始前核对阻塞产物、仓库状态和已有领取记录，依据实际协作技能确定文件所有权；本草案不冒充已经完成的任务领取。接口不足时回报具体需求及受影响任务，不能在本任务内复制第二套共同规则。

## 验收条件

- [ ] 对手按内容目录的公开规则行动，摘要与其现金/资产一致，玩家与对手不共用账本。
- [ ] 每回合只推进一次对手行动，切镜头或恢复不会额外推进。
- [ ] 合作价格 100、优质工具次日交货、一局一次，交付前工具不增加收入。
- [ ] 已有工具时不再次卖合作工具；拒绝或错过不会封锁普通工具、工作或终局。
- [ ] 对手先达标改变其店面，玩家仍完成全部八回合；不因画像改变对手策略。
- [ ] 角色动作和小店状态双视角一致，合作接受/拒绝各有实际回应。
- [ ] 执行[视觉生产流程](../../design/visual-production.md)：imagegen 效果图 → 生成并使用元素图 → 真实三维/界面 → 运行截图对照；提交对应证据。

## 完成证据

接受/拒绝/已持工具三条合作路径，以及对手先达标仍可继续的演示。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
