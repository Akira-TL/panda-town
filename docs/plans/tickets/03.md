## 验收条件

- [ ] 按内容目录建立十二主路点与四支路点的连通关系，视觉为连续弯路、坡道和桥梁，没有地板格。
- [ ] 每条边一步；掷骰不足时停在途中，经过岔路保留剩余点数，不能折返刷事件。
- [ ] 岔路给出两个方向的地标预览与步数信息；相同骰子配不同分支可到达不同地点。
- [ ] 第三人称与可旋转缩放的全局镜头使用同一场景，切换期间不推进状态、不重掷或重复事件。
- [ ] 移动途中经过地点不弹主要事件；最终落点只触发一次，快速切镜头不丢动作。
- [ ] 检验跨循环起点、恰停岔路、连续经过分支、剩余一步四类导航情形。
- [ ] 交付每个地点的坐标/朝向/插槽范围，使地区任务仅填自己的地标和角色。
- [ ] 执行[视觉生产流程](../../design/visual-production.md)：imagegen 效果图 → 生成并使用元素图 → 真实三维/界面 → 运行截图对照；提交对应证据。

## 完成证据

两条不同岔路录像或截图序列、路线可达检查与双视角对照。

交接时给出实际修改范围、验证结果、产物位置、已知差异和下一任务接入说明。没有运行或生成的产物不得标为完成。
