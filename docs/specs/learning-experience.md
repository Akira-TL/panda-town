# Panda Town 游玩学习与PandaAI衔接规格

生效：2026-11-01。父需求为GitHub #10，本轮总目标已激活。
本规格在[连续商店交易合同](shop-trading.md)上补充游玩学习、指标、对照和结算引导，
保留持续账户与随时结算。固定八章、八轮强制终局及旧咖啡馆解锁不再适用。

## 1. 权威输入与体验目标

本轮直接依据用户的[开发执行提示词](../art/production/learning-scenes-20261101-v1/开发执行提示词.md)
和[量化知识与游戏映射](../art/production/learning-scenes-20261101-v1/量化知识与游戏映射.md)。
同目录01至10制作参考用于视觉对照；图上的数值、价格线与示例文字不进入运行计算。
源参考与实际运行截图分别记录，不把生成图当作已经可玩。

玩家是小镇交易节商人，初始1000枚小镇币。表层目标是经营商品、让账户资产增长；
学习通过观察行情、表达办法、主动买卖及下一期账户变化发生。
建议5–8分钟面向零金融基础参观者，时长不是强制计时或轮数门槛。
单人体验，电脑优先兼容手机，不要求固定店铺顺序或逛完八店。

## 2. 连续交易与三维世界

保留掷骰自动行走、两处分支、弯曲道路、无棋盘地板格、16地点和真实三维形体。
跟随与全局镜头均能查看小镇，并提供可操作的旋转视角；每个途经点检查主角与店铺可见性。
15个新增居民使用用户交付模型加工，分别有身份、位置和相关回应；加载模型不等于身份互动已验收。
每处人物和活动物件留出道路与主角空间，不能用平面概念图遮住三维场景。

八主要店分别售面包、木材、水果、芯片、金券、花束、咖啡豆、茶叶，
唯一商品与历史产品映射为 `src/trading/products.ts`。
户外点沿既有映射提供报价或交货机会，不创造第二条同商品价格。
岔路提前显示已知商品与已观察行情特点，不能泄露将来涨跌。

一次回合到达后，只做一次主要买入、加仓、持有或卖出。
买入限当前店商品；背包中已有商品可跨店卖出，仍占本轮行动。
查看资料、选择背包、设置规则与可跳过互动不额外推进行情或扣回合。
下一站直接开始新一轮骰子行程，每次完整到达所有商品共同推进一个日历日。
设置打开暂停行走；移动、岔路、决策、反馈阶段都可主动结算。
结算按当前市值冻结快照，不伪造平仓或额外卖出费；历史末尾停止并仍可结算。

## 3. 从行情到后果的最小闭环

主卡以商品、实际K线或折线、数量、现金与背包为主，三个主要操作无需滚动同时可见。
文字优先一句短提示，详情由玩家点开。界面使用用户选定的奶油白、浅金、森林绿与立体商品元素，
保持暖纸张材质、清楚层次和桌面/手机的一致操作结构。

交易前显示实际可成交量、含费支出或净收入、交易后现金及持仓预览，清楚标记为预览。
仓位预设以真实单位与费用计算；目标投入上限和最终实际比例分别说明。
成交后用商品数量、现金前后值、费用和真实成交点对应反馈，不能只换静态段落。
下一期同时区分所选商品变化与全部持仓的估值变化。
平均持仓成本含买入费，零持仓不画成本线；金色虚线仅指当前平均成本。

固定手算：1000现金在100买2份，0.1%费用后现金799.80、成本200.20；
下一期95时市值190、总资产989.80、未实现盈亏-10.20。
部分卖出按比例释放成本，已实现和未实现盈亏分开；量、现金、持仓不足真实限制成交。

## 4. K线、量价与参考线

八商品各保留真实开高低收及成交量，同资产四价使用同一个首日开盘缩放比例，量反向换算。
原日期/开盘/收盘/量逐位保持，最高/最低从原CSV补齐，不以实体编造影线。
当前固定200日，初始公开20期前史；仅可见前缀参与图形、纵轴、均线、提示和触发判断。
数据及许可见[来源说明](../design/shop-market-data-source.md)。

K线点按能查看对应日的实际四价，实体连接开收盘、影线延伸高低价；
颜色有方向文字或图例，不仅依赖红绿。K线阴阳与相对昨收的日涨跌区分。
折线与K线切换保持同一商品、日期和当前价；没有分钟/周线数据时不做假频率切换。
成交量柱与日期对齐，单位为换算份额，不冒充成交额或真实盘口。

既有 `ma5/ma20` 是排除当期的此前5/20期均价，图例继续明确“此前均价”。
前高为此前20根最高价最大值，排除当期；五期量比为当期量/此前5根均量。
预热不足或分母0返回空值，不把未知画成0或从未来补线。

## 5. 明确表达规则

玩家主动表达“什么时候买／投入多少／什么时候退出”。保存明确选择，仍可手动交易，
不能从一次买入倒推长期策略，也不能把图上条件当作已经启用的自动订单。
规则投入上限有25%、50%、75%；入场、退出条件及预热状态可在当前已知图上核对。

| 条件                   | 当前实现口径                                       |
| ---------------------- | -------------------------------------------------- |
| 手动                   | 无自动判断，结果为空值                             |
| 均价上穿/下穿          | 前收与前点此前20均价、今收与今点此前20均价分别比较 |
| 前高突破               | 当前收盘高于此前20根最高价，不把当期高价放进参考   |
| 指数均线               | 收盘上穿12期指数移动平均线                         |
| 指数平滑异同移动平均线 | 差值线上穿信号线                                   |
| 相对强弱指数           | 上穿30                                             |
| 随机指标               | K上穿D                                             |
| 布林带                 | 收盘上穿中轨                                       |
| 平均真实波幅           | ATR/收盘达到3%，只表示波动条件，不说成方向信号     |
| 含费成本退出           | 收盘低于或等于含费均价95%，仍由玩家确认卖出        |

## 6. 六项指标研究与完整交互

研究抽屉一次最多展开一种辅助指标，六项均可切换且使用真实计算、参数说明、当前值或历史不足。
包括指数移动平均线（EMA）、指数平滑异同移动平均线（MACD）、相对强弱指数（RSI）、
随机指标（KDJ）、布林带和平均真实波幅（ATR）。完整公式、种子和边界见
[指标研究依据](../research/trading-indicators.md)，不得在界面另算另一套结果。

至少实际完成：查看MACD图形→点一处已发生的交叉→读一句当点解释→明确决定是否加入规则→
在新商品或新日期判断该规则是否触发。其他指标复用交互结构，不能仅列名称或绘制装饰曲线。
MACD柱为差值减信号、不乘2；完整值最早索引33，判断交叉还需前一个有效点。
随机指标J可越0至100；ATR是价格单位幅度，不能解释为收益率或保证反转。
布林带中轨含当期20个收盘，与排除当期的既有均价分开标注。

## 7. 两种可跳过客观互动

第一种为帮店员挂价格牌：从一根已知、非平实体K线识别开盘/收盘，选择真实数值。
第二种为帮学徒判断：明确采用规则后，到新商品或新日期，判断当前已知条件是否触发。
无明确规则或历史不足时不假出题，玩家可继续正常交易。

作答前选项视觉权重一致，不展示勾叉、正误颜色或默认正确选择。
领域模块根据当时数据核对，不信任界面传来的“正确”。首次判断冻结；跳过不算错误，
重复点击不增加证据。仅描述相应题目与情境，新情境应用与首次辨认分开记。
主动查看、点选指标、明确采用和客观答题是四类不同证据，不能相互替代。

## 8. 同条件电脑商人与账户回撤

电脑商人与玩家从同一1000起点、相同回合落点和已知行情开始。
公开固定政策：先按固定商品顺序退出收盘低于此前20期均价的已有持仓，
否则在当前店收盘上穿此前20期均价时申请买至总持仓半仓。
每轮仅一个主要行动，买当前店或卖已有商品，费用0.1%，量与现金受同一交易引擎约束。
申请卖清若受量限制可部分成交，不能伪称全数退出。

对照只跟随玩家已经完成的主要决定行动；当前尚未决定时仅做市值估算，
并显示各笔原因、政策与比较起点。不得读取将来择优改政策或拥有额外资金/机会。
账户曲线由真实成交与到达日期重放，区分到达估值和扣费后点。
最大回撤从已观察的账户高点向后计算，不用日内最高/最低虚构账户路径。

## 9. 结算与PandaAI

精简结果页只突出总资产、盈亏、最大回撤；明确选定办法或“本局手动交易”；
两三项可追溯交易/学习事实；一个来自本局事实的研究问题。
零交易、零作答、没有规则时明确未知，不暗示已有几次操作、已掌握知识或形成长期人设。
相反选择与信息变化保留，盈亏不换算人格、编程能力、心理诊断或适当性。

“去 PandaAI 验证 ↗”由玩家主动打开
[PandaAI智能体量化页面](https://www.pandaaiquant.com/agent_quant/)，为普通网页跳转。
“复制我的问题”主动复制明确规则或手动状态、真实资产/费用/回撤/交易数、客观互动事实与研究问题。
复制失败准确反馈；不声称已发送，不自动携带画像或启动交易。
文本明确小镇商品是历史金融产品映射，不是真实证券代码，尚未由PandaAI验证。
保留按需依据、重开与清除，不另加注册或强制课程。

## 10. 本机数据与验证门槛

交易与学习使用各自版本化键并按同一局标识关联，默认只在本标签页保存。

存储读写拒绝仍可内存游玩，删除失败明确残留风险，不虚报清除成功。

已存在的作者局部证据：市场7项、指标10项及连续账本/恢复专项包含手算和前缀检查；
