# Panda Town 当前产品规格

更新：2026-11-01。当前授权版本是连续商店交易；固定八章、八回合、独立重置1000的回测和咖啡馆/策略展门槛已经退役。本规格与[商店交易共同合同](shop-trading.md)共同适用，算法、状态和字段以该合同及src/trading/model.ts为准。

## 主路径

玩家为零金融基础的展会参观者。真实三维童话小镇中保留16地点、弯曲无棋盘街道、掷骰自动行走、岔路选择、跟随和全局镜头。仅最终落点打开交易；路过不另触发主要行动。

开局1000模拟币，一局一个持续账户。每轮主要行动为买入、持有或卖出；后续轮次可继续加仓。购买当前店商品，已有商品可从背包在后续任意商店选择卖出，卖出占本轮主要行动。“下一站”开始下一轮，完成到达后所有商品行情一起推进一日。

八家商店分别对应面包、木材、水果、芯片、金券、花束、咖啡豆、茶叶；唯一映射在src/trading/products.ts。八个独立真实历史产品采用相同固定日期，各自首日开盘归一至100，成交量反向缩放。初始市场索引19，公开20期前史；最后索引199，不循环、不造未来。来源和许可见[八商品历史来源](../design/shop-market-data-source.md)。

## 交易、结算与反馈

买卖按当前已公开报价进行纸上模拟，费率0.1%。现金、数量、含费成本和已实现盈亏实际计算，资金或成交量不足真实限制成交，不能借款、卖空或重复入账。持有不收交易费，持仓随市场变化产生市值变化。

价格线、此前均线和真实成交标记为实际组件，仅显示已知前缀，不提前泄露未来价格或纵轴极值。数量默认1份。图形主导，文字只解释当前操作和变化；可选资料不消耗主要交易行动。

右上设置打开时暂停行走，任何阶段都能主动结算。结算保存当前现金、持仓市值、费用和盈亏的快照，不自动平仓。没有固定八轮结局，5–8分钟是建议展会体验时长，玩家自行决定结束。

## 画像、PandaAI与数据

结束直接进入精简画像，可展开实际交易和查看证据。事实来自本局主动操作、实际机会和真实账户；随机落点或自动显示不算兴趣。重复查看去重，证据不足或相反证据准确呈现。不以盈亏给人格、能力、适当性或心理诊断评分；一般人格缺乏观察则未评估。

PandaAI官方入口由玩家手动打开，不自动跳转或传送画像。PandaData和真实执行服务尚未接入，状态准确标注。默认仅本机当前标签页存储，交易版新键和版本拒绝混入旧研究记录；重开、清除、失败提示和跨局隔离需按新版本验证。

## 视觉、运行与完成门槛

沿用已批准的童话风格和真实模型，执行[视觉生产要求](../design/visual-production.md)：效果图、元素图、实际三维/组件、截图对照。八店正常营业，茶馆是普通售茶店；相机不被旧展示参数劫持。手机保留角色与主操作，触控及键盘可用，减少动画不改变交易结果。

单个运行负责人通过scripts/*.sh启停，日志写logs/。先检查独立手算与市场边界，再在最新构建完成两条不同交易路径、超过八轮、背包跨店卖、设置暂停及随时结算；补齐刷新、清除、手机、键盘、资源故障、视觉与真实设备证据。

当前新的核心和UI浏览器QA尚未完成。旧八章、开店版和旧画像通过记录保留历史范围；T01–T24及GitHub #10–#34按新条件保持待验证，不因文档同步、素材存在或模型加载关闭。
