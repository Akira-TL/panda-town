# Panda Town 当前产品规格

更新：2026-10-31。用户已确认以“八天完成自己的量化策略，在小镇策略展展示”为唯一目标，替代旧开咖啡馆主线。当前实施共同规则由本文及[量化研究实施合同](research-core.md)组成；剧情全文见[主线与文案](../design/quant-story-and-copy.md)。旧版合同保留在Git历史f809d71，旧消费/开店测试不证明新内容完成。

## 产品与主路径

面向零金融基础的展会参观者，固定八回合，目标体验5–8分钟；电脑优先兼容手机。玩家在真实三维童话小镇中掷骰自动走、岔路选方向，在最终落点完成当日研究章节。一天只提交一个主要选择，阅读与查看资料不限时。

八章固定顺序：研究意图、检查数据、生成规则、历史回测、投入比例、新数据检验、费用与成交、策略展。所有合法骰序列都能接触完整研究链；地点改变角色、导语和附加资料，不随机剥夺核心研究工具。

唯一完成目标是展示一份含规则、数据、验证记录、风险和未知部分的策略。小规模模拟、修改或暂缓均有完整结尾，不按收益、知识题或开店资金门槛淘汰。电脑研究者提供统一条件下的比较，不读取玩家画像操控机会。

## 模拟与证据

采用本地版本化虚构行情，实际计算规则、交易、费用、资金曲线、对照和回撤。规则条件、研究/检验区间、撮合时点、仓位与费用口径见共同合同。信号不能使用未来信息；已揭晓数据不能反复当成未见样本。相同输入可重复得到相同结果。

PandaAI展示价值落实在可操作的研究工作台与证据解释。当前未接入PandaData或真实PandaAI执行服务，界面准确标注“研究流程演示｜本地计算｜尚未连接PandaData”。不能用模板文字或预置盈利图冒充运行结果。

研究兴趣、数据与验证习惯、策略/资金取舍、工具使用、已答知识、未知与变化分区展示。每条事实指向真实选择或主动操作，不根据收益、骰子落点、速度或一次自动解释推断能力或人格。一般人格无合适情境时未评估；不填百分比或心理分。

两道客观理解题可跳过、只记首次答案，不奖励金币、不消耗主要选择；报告只显示正确数/已答数、原题与解释。

## 三维与视觉

沿用已选童话小镇：暖色日光、柔和阴影、木构灰泥、错落建筑、弯路、溪流与桥。地图保留12主路和4支路地点，无棋盘格。第三人称默认、全局可旋转缩放；切镜头不改回合或重复触发事件。

继续遵守[视觉生产](../design/visual-production.md)：效果图→生成并使用元素→真实三维/界面→运行截图对照。已接收的熊猫、八建筑和树模型复用；需要新模型时Agent生成输入图打包至Downloads，用户Tripo生成后交付，Agent通过Blender CLI加工和集成。未核实许可不改标MIT。

新量化工作台与画像先生成参考和元素，数字、文字、图表、选择与证据必须是真实组件。不能把概念图当成可玩场景或计算结果。

## 恢复、交互与性能

行为默认仅保留当前标签页一局，版本3，拒绝旧版或损坏记录；重开、清除、存储拒绝有准确反馈，不自动上传至开发者或PandaAI。结束直接到画像，不新增推荐、额外练习、注册或外部跳转。

原生键盘操作、模态焦点循环和归还、44像素触控、长文可关闭、减少动画均覆盖同一主路径。启停通过scripts/*.sh，日志写logs；不能误停其他项目。

性能预算：桌面60帧/秒、移动30帧/秒；实际记录具体设备、浏览器、分辨率与至少60秒的中位及95百分位帧间隔。首屏传输15MB、首局40MB。模拟手机视口不能冒充实体设备；所有尚未验证项保留事实边界。
