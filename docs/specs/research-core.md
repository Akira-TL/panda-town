# 量化研究主线的实施合同

2026-10-31。用户已确认唯一目标改为八天完成自己的量化策略、参加小镇策略展。本合同将[完整剧情与文案](../design/quant-story-and-copy.md)落实为可实施的共同规则，替代旧开店版经济与消费画像。八天任务采用固定顺序，场景和骰子路线继续复用。

## 1. 当前有效的范围

零金融基础、电脑优先兼容手机，目标5–8分钟。保留真实三维童话小镇、16地点、两处分支、六面骰自动行走及双镜头。仅最终落点触发一天的主要选择；路过、切镜头、资料展开不推进主要行动。八个章节与落点分离，任意合法路线均能完成。

唯一目标是形成可解释的策略展品。第八天选择小规模模拟、修改或暂缓，都完成展示；不按盈利、答题或3000金币开店判定成功。模拟运行选择仅记录本局态度，不启动真实或外部交易。结尾直接进入量化画像，只有证据、重开和清除，不增加推荐、课程、注册和外部跳转。

## 2. 共同类型与职责

共同类型放在 `src/research/model.ts`。新主线不修改旧 `src/game/engine.ts` 的现金来模拟收益，不混用旧资产账本；旧 `content.ts` 的地点和路线暂供导航复用，不调用其中的旧消费事件。

| 模块               | 唯一职责                                     |
| ------------------ | -------------------------------------------- |
| `data.ts`          | 固定演示数据、原始问题记录和可公开的研究段   |
| `simulation.ts`    | 从明确输入计算交易、费用、资金曲线和指标     |
| `campaign.ts`      | 八章阶段、主要选择、运行记录、幂等和证据     |
| `chapters.ts`      | 按章节及地点提供中文剧情、三选项和可查看主题 |
| `profile.ts`       | 从真实证据派生量化研究画像，不修改状态       |
| `session.ts`       | 当前局恢复与结构/版本/边界验证               |
| `app/page.tsx`     | 一次开局、掷骰移动、岔路、界面装配与存储     |
| `src/research/ui/` | 工作台、真实图表、资料/理解题及画像界面      |
| `src/scene/`       | 只读位置与研究展示状态，不另算经济或画像     |

## 3. 八章选择及状态

`ResearchState.version` 为3；阶段为 `travel`、`decision`、`feedback`、`exhibit`、`report`。每个动作带唯一标识和日数，拒绝旧日、重复或错误阶段动作；核心不修改传入对象。

`arrive` 只在移动结束后进入当天决策并冻结地点。`choose` 一次进入反馈，`continue` 推进下一天；第八天反馈继续后到展品，`report` 才到画像。刷新或连点不能再次运行、推进或覆盖首次答案。

| 天数 | 主要选择与真实后果                                                 |
| ---- | ------------------------------------------------------------------ |
| 1    | 收益/控制下跌/减少操作，记录自述意图，不直接贴风险标签             |
| 2    | 核对来源/定位问题/自动检查并解释；显示相应检查，统一使用核验数据   |
| 3    | 趋势/均值回归/固定配置，保存明确规则与版本1                        |
| 4    | 优先比较对照/下跌/交易，运行研究段，标准投入100%、初始1000且费用0  |
| 5    | 投入30%/60%/保留现金，研究段重新计算，保留前一运行                 |
| 6    | 检验原版/先看说明后检验/暂缓；运行才标已检验，不运行保留未检验状态 |
| 7    | 计10基点费用/减为每5期调整且计10基点/提高为30基点；实际重算研究段  |
| 8    | 模拟/修改/暂缓，形成展品，不影响是否可以查看完整画像               |

第六章若主要选项含“先看说明”，必须实际展示说明并允许明确运行，不能空耗主要回合后把未运行记成已运行。第七章改变规则、仓位、频率或费用后，原检验结果保留，当前版标“需要新数据验证”；不再将已揭晓段自动称作未见数据。

## 4. 演示数据与计算

使用两项明确虚构的模拟资产 `bamboo`、`pine`。固定数据200期：20预热、120研究、60后续检验。每期日期、开盘、收盘和成交量均明确；缺失/异常接收记录与核验后的记录分开保存。恢复记录采用固定原始演示序列，不用未来信息插补。数据版本及生成方法可复核，不冠以真实PandaData来源。

策略规则清楚写明条件和固定参数，不在检验段搜索最好参数。前一期收盘形成信号，下一期开盘执行；预热只供历史窗口，不能参与之前交易。投入比例为0、0.3、0.6或研究比较用的1，总投入不超过现金；虚构份额可为小数，不冒称真实A股整手成交规则。无借款、负现金、做空或杠杆。

费用以基点输入，1基点为万分之一。买卖费用实际扣款；滑点影响实际成交价格，不能只显示提示。结果包含每笔信号与成交日期、数量、价格、费用、成交后现金，及每期资金曲线。对照统一为同一期间、相同初始资金与费用假设的等权持有；口径必须在界面解释。

净收益、期末资产、最大回撤、总费用和交易次数从同一次运行计算。最大回撤包括初始资金起点；现金持有的收益为0，资金1000平线。相同输入得到相同结果，运行标识不依赖当前时间或随机数。

PandaAI工作台明确显示“研究流程演示｜本地计算｜尚未连接PandaData”。实际接口和数据权限未接入前不伪称调用成功。数据、策略和回测仅构成本游戏教学模拟，不启动外部交易。

## 5. 证据与画像

主要选择、主动查看、运行与答题分别记录。每条含本局标识、日数、独立情境、地点、实际展示选项、主动查看主题、规则与版本/仓位、引用运行及后果。只有看见并可选择的机会进入分母，不能把随机地点当兴趣。

画像主区块为研究兴趣、证据习惯、策略与资金取舍、工具使用、已答知识和未观察部分。意图是自述，操作是事实，知识来自客观题；三者区分。相同章节重复点击不增加独立情境；至少两个不同情境支持时才概括“本局多次”。这个阈值是展示规则，不是心理测量效度声明。

策略收益与个人画像分区。不能根据盈利、亏损、趋势规则、自动解释或单次仓位给出能力分、人格等级、现实适当性结论。相反选择并列展示及其信息变化。一般人格无合适情境则未评估，不能为了填满卡片补默认分。

理解题仅两道：历史盈利是否保证未来盈利、加入费用是否提高同组交易净收益，正确均为“不”。题目可跳过，首次答案冻结，答题不改变资金或主要选择。仅报告正确数/已答数、原题和解释，不换算综合能力。

## 6. 本机恢复与设备

只保留当前标签页一局，存储包含版本3及路线上下文。拒绝旧版或损坏记录并明确重开，不静默拼接消费证据与研究证据。保存失败时允许内存完成，删除失败准确说明残留；默认不上传。

沿用原生按钮、模态窗口焦点进入/归还、Escape、首尾循环与重开清除的默认取消。手机按钮至少44像素，长内容保持关闭按钮可见，减少动画缩短移动及演出但不跳过文字、选择、资金或结果。

## 7. 完成证据

先验证可独立手算的计算，再以真实按钮从开场至画像。至少覆盖两条不同策略/仓位/检验决定的完整路线；确认同收益不同研究操作可产生不同事实描述、同操作遇不同结果不自动改变人的观察。另核对恢复、重开、清除、错误资源、手机和仅键盘。

视觉继续遵守已选参考图及生成素材链，保留真实场景和实际运行对照；新工作台与画像先生成对应效果图及元素再制作。完整版本的首屏15MB/首局40MB预算、具体设备性能及真实5–8分钟试玩分别按实际证据记录，不把单元测试或模型加载当作全部完成。

旧开店版已通过的记录保留历史范围；新内容对应的GitHub任务重新定义后逐项验证，不能沿用旧消费画像或开店余额的绿灯。
