# 商店交易版本共同合同

2026-10-31最新用户修正覆盖旧八章研究流程：每家商店对应不同交易商品，玩家决定买入、加仓、持有或卖出；不限制八轮，右上角设置随时结算。沿用三维小镇、骰子自动走、岔路、真实历史走势、少字图形界面和PandaAI按钮。

## 实际循环

开局现金1000，第一次掷骰开始第1轮。仅最终落点打开对应商品的交易卡，八家主要店各有独立商品与历史产品；户外点为相应商品的报价/交货点，不另造相同商品的第二个价格。

买入/卖出按当前已显示报价模拟成交，费用固定0.1%，明确不是实盘撮合。数量控件默认1份。购买对应当前店铺；已持有商品可从背包在后续任意一轮选择卖出，避免被随机落点锁住退出机会。卖出仍占本轮主要决定，不能同轮刷多笔主要行动。买入后可继续加仓或卖出；未持有时“持有”显示“先看看”。订单、现金、数量、费用、成本和已实现盈亏均实际计算，不用独立回测重置资金。买卖只在交易阶段一次执行，反馈用成交点、商品数量及现金前后差值表示。

“下一站”直接启动新一轮掷骰，省掉重复确认；每个完整移动回合到达后，所有商品行情共同推进一日。价格图只展示已经经历的历史和初始20期前史，不显示未来价格或未来纵轴极值。商店不同则商品不同，不能把两条曲线换名字冒充八种产品。

无固定八轮结局。历史样本播到末尾后明确提示，不拼接或随机造未来；仍可结算。设置打开时暂停行走。结算可在任何阶段主动执行，按当前现金与持仓市值形成快照，不伪造自动卖出或卖出手续费。

## 商品与来源

八个ProductId及店铺、名称、真实历史产品映射由src/trading/products.ts唯一维护。商品是游戏设定，价格走势使用各自真实历史日线按首日开盘缩放为100，数量反向换算；原始数据、校验值、许可保留。未接入PandaData或真实PandaAI执行服务。

市场接口由src/trading/market.ts提供：MARKET_VERSION、START_MARKET_INDEX（19）、LAST_MARKET_INDEX、getQuote(product,index)、getMarketDate(index)、getVisibleSeries(product,lastIndex)。每项ProductQuote返回日期、开收盘和数量；ProductPricePoint只含公开前缀的当前价、此前均线与涨跌。

## 状态与模块

共同类型为src/trading/model.ts。核心接口为createTradingGame(sessionId)、dispatchTrading(game,action)、getAccountSnapshot(game)、previewTrade(game,side,quantity)，由src/trading/engine.ts维护。每个动作唯一id，拒绝重复、错误阶段及无效数量，不修改传入对象。

phase为travel/decision/feedback/report；初始round=0、marketIndex=19。start-round由初始travel或feedback开始一轮，round+1；arrive在移动结束时冻结落点、marketIndex+1（不越末尾），记录持仓随价格变化的arrivalDelta。buy/sell/hold转反馈；inspect不消耗回合且同轮同产品主题不重复计；settle在任何阶段生成快照并进入report，之后不再移动或交易。

现金不得为负或借贷。持仓quantity/costBasis明确记录，买入成本含费；卖出按数量比例释放成本，净卖款减对应成本为已实现盈亏。未实现盈亏为当前市值减剩余成本；总盈亏=总资产-初始现金。不能凭空卖出未持有商品，成交量/现金不足必须真实限制；原始记录保留实际成交数量。

导航、存储、画像与页面由协调者维护。存储使用新版本/新键，旧八章记录不接续；默认仅当前标签页。结束画像记录实际商品交易、现金与持仓取舍、盈亏环境和主动查看；随机落点或自动显示不计兴趣，不用收益换算人格/能力。旧八章和旧画像测试只证明旧版本，不证明新交易循环。

## 视觉

先用imagegen生成交易版参考，再生成需要的商品元素，真实组件照图实现。主卡突出商品、价格线、持仓/现金与买卖，短文案解释原因与变化；不恢复长文教学。游戏结束保持精简画像、可展开证据、重开/清除及用户主动打开PandaAI官方主页的入口，不自动传送画像。

页面使用TradingPanel({game,onAction,quantity,onQuantityChange,reducedMotion})和TradingReport({game,onRestart,onClear})；图表只画当前商品的已知价格与真实买卖。运行只由协调者通过scripts/*.sh启停，其他Agent不构建或启停。
