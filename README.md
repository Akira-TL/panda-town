# Panda Town

面向 PandaAI 赛道的三维童话小镇游戏规划：玩家掷骰子沿弯曲街道自动行走，在岔路、商店与角色事件中选择，经营生活与资产，并查看带行为证据的消费偏好与一般人格特征反馈。

**当前处于规格和任务拆分阶段，尚无可运行游戏。用户要求先把内容定下来，本轮不进行开发。**
